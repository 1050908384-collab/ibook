> **适合人群**：从未用过 Linux、没用过虚拟机的纯小白。每一步都拆解到"点哪里、输入什么"，你只需要跟着做。完成本章后，你将拥有一台可用的 Ubuntu 环境，并掌握终端的基本操作，为后续学习 Python、PyTorch 与大模型微调打下坚实基础。（①）

## 一、先搞清楚三个问题（看完再动手，避免常见踩坑）（①）

### 1.1 什么是 Linux？我为什么要装它？（①）

你平时用的 Windows 或 macOS 叫"操作系统"，Linux 是另一个操作系统。全世界绝大多数服务器（网站后台、云服务、AI 训练集群）跑的都是 Linux。学编程到后面，你大概率要和它打交道。

本教程用的是 **Ubuntu 24.04 LTS**（长期支持版），厂家会持续提供多年安全更新，稳定且适合入门。如果你已安装 Ubuntu 22.04，后续步骤同样适用。

### 1.2 "虚拟机"、"WSL2"、"云服务器"到底选哪个？（①）

| 方案 | 一句话解释 | 优点 | 缺点 | 推荐谁用 |
|---|---|---|---|---|
| **虚拟机** | 在你现在的电脑里"模拟"出一台新电脑 | 最像真服务器，完全隔离 | 占内存（建议至少 4GB）、电脑配置低会卡 | 电脑内存 ≥ 8GB 的用户 |
| **WSL2** | Windows 自带的"Linux 子系统"，像装了个 App | 轻量、启动快、和 Windows 无缝互通 | 仅限 Win10/11，部分高级功能受限 | 用 Win10/11 且不想折腾的用户 |
| **云服务器** | 租一台阿里云/腾讯云的远程电脑 | 有公网 IP，随时随地连，不占自己电脑资源 | 需要付费（学生通常可享受优惠，以官网当前价格为准）、需要网络 | 想随时远程开发、电脑配置低的人 |

> **建议**：通常建议优先选择 **方案二（WSL2）**，安装通常几分钟即可完成。只有 WSL2 装不上、或者想体验完整 Linux 桌面，才选方案一（虚拟机）。

### 1.3 三个方案最终都要达到什么效果？（①）

不同方案的最终开发体验是一致的：

1. 有了一台运行 Ubuntu 24.04 的"电脑"（虚拟的或远程的）
2. **虚拟机 / 云服务器**：能通过 SSH 从你的 Windows 连过去操作它（就像远程控制）；**WSL2**：可直接与 Windows 互通，并通过 VS Code 本地开发
3. VS Code 装好插件，写代码有高亮、自动补全、能调试

> **SSH 是什么？** 通俗理解就是"远程桌面命令行版"。你不用跑到服务器面前，在自己电脑上敲命令就能控制另一台电脑。虚拟机与云服务器需要它；WSL2 则通过 Remote-WSL 插件直接集成，无需手动配置 SSH。

## 二、方案一：虚拟机（VirtualBox + Ubuntu 24.04）（①）

> **开始前检查**：你的电脑内存有没有 8GB？右键"此电脑" → "属性" → 看"已安装的内存(RAM)"。如果 < 8GB，请跳到方案二或三。

### 2.1 下载 VirtualBox（虚拟化软件）（①）

**什么是 VirtualBox？** 它是一款开源的虚拟机软件，能在你的 Windows 里凭空造出一台假电脑，这台假电脑可以装任何操作系统。

1. 打开浏览器，地址栏输入：https://www.virtualbox.org/wiki/Downloads
2. 找到 **"VirtualBox 7.x.x platform packages"** 下的 **Windows hosts** 版本，点击下载
3. 下载完成后，双击安装包
4. 安装过程：
   - 点"下一步" → 一路保持默认选项
   - 到"安装"按钮时点一下，等待进度条跑完
   - 最后点"完成"

> **常见坑预警**：安装过程中如果弹出"是否允许此应用更改你的设备"，点"是"。如果杀毒软件拦截，选择"允许"或"信任"。

### 2.2 下载 Ubuntu 24.04 镜像文件（①）

**什么是镜像文件（.iso）？** 你可以把它理解成一个"操作系统安装光盘的电子版"，VirtualBox 通过这个文件来安装系统。

1. 浏览器打开：https://releases.ubuntu.com/24.04/
2. 找到文件名类似 `ubuntu-24.04.x-desktop-amd64.iso`（x 为具体小版本号），点击下载
3. 文件大约 5GB，下载需要几分钟到十几分钟（取决于网速）
4. 下载完后 **不要双击打开它**，就放在下载文件夹里就好

> **常见坑预警**：很多人下错版本。确认你下的是 `desktop-amd64.iso`，不是 `server` 版（server 版没有图形界面，纯黑色命令行，对新手不友好）。

### 2.3 在 VirtualBox 里创建虚拟机（①）

1. 双击桌面上的 **"Oracle VM VirtualBox"** 图标打开软件
2. 点击窗口上方的 **"新建"（New）** 按钮
3. 弹出窗口，填写：
   - **名称**：`Ubuntu-24.04`
   - **文件夹**：选择安装位置（**不要放 C 盘**，建议选 D 盘或 E 盘）
   - **类型**：`Linux`
   - **版本**：`Ubuntu (64-bit)`
   - 点"下一步"
4. 分配内存大小：
   - 拖动滑块到 **4096 MB**（也就是 4GB）
   - 点"下一步"
5. 虚拟硬盘：
   - 选 **"现在创建虚拟硬盘"**
   - 文件位置默认即可，大小填 **60 GB**
   - 类型选 **VDI**，存储选 **动态分配**
   - 点"完成"
6. 调整处理器核心数：
   - 选中刚创建的虚拟机，点 **"设置"（Settings）**
   - 左侧选 **"系统" → "处理器"**
   - **处理器数量**：`1`，**每个处理器的核心数**：`2`（总共分配 2 核）
   - 左侧选 **"存储"**，在"控制器"下点击光盘图标，选择 **"选择虚拟盘"**，找到你下载的 `ubuntu-24.04.x-desktop-amd64.iso`
   - 点"确定"

### 2.4 安装 Ubuntu 系统（①）

1. 在 VirtualBox 窗口里，选中虚拟机，点 **"启动"（Start）** 按钮
2. 等几十秒，会出现 Ubuntu 安装界面：
   - 左边选语言，选 **"中文(简体)"** 或 **"English"** → 点"安装 Ubuntu"
   - 键盘布局：默认不用改，点"继续"
   - 更新和其他软件：选 **"正常安装"**，勾上"安装 Ubuntu 时下载更新"和"安装第三方软件" → 点"继续"
   - 安装类型：选 **"清除整个磁盘并安装 Ubuntu"**（不用怕，这里的"磁盘"是你虚拟机的 60G，不会影响你真正的 C 盘 D 盘）→ 点"现在安装" → 弹窗点"继续"
   - 时区：在地图上点一下中国的位置，或输入"Shanghai" → 点"继续"
   - 用户信息：填名字、计算机名、用户名、密码 → 点"继续"
3. 现在开始自动安装，大约 10~20 分钟
4. 安装完后会提示"安装完成，您需要重启计算机"，点"现在重启"
5. 重启后如果提示移除安装介质，在 VirtualBox 菜单栏点 **"设备" → "光学驱动器" → "移除虚拟盘"**，然后按回车
6. 输入密码登录，看到桌面就完成了！

> **常见坑预警**：如果安装过程卡住超过 30 分钟不动，关掉虚拟机重新来一次，一般第二次就顺利了。

### 2.5 安装 SSH 远程连接工具（①）

**什么是 SSH？** 前面说了，等于"远程桌面命令行版"。装了 SSH 之后，你在 Windows 的终端里敲命令，就能直接操控虚拟机里的 Ubuntu，不用来回切换窗口。

1. 在 Ubuntu 桌面空白处点 **鼠标右键** → 选 **"在终端中打开"**（Open in Terminal）。如果右键没有，按键盘 `Ctrl + Alt + T` 也能打开终端
2. 依次输入以下命令（输完一行按一下回车）：

```bash
# 第1步：更新软件列表（类似"刷新一下应用商店的货架"）
sudo apt update

# 第2步：安装 SSH 服务（让别的电脑能远程连过来）
#     openssh-server 是 SSH 服务端
#     net-tools 提供 ifconfig 命令，用来查看 IP 地址
sudo apt install -y openssh-server net-tools

# 第3步：设置 SSH 开机自动启动
sudo systemctl enable ssh

# 第4步：立刻启动 SSH 服务
sudo systemctl start ssh
```

> **sudo 是什么？** `sudo` = "以管理员身份执行"。Linux 里普通用户不能随便装软件，加了 sudo 就相当于"给我最高权限，让我干这件事"。输入 sudo 命令后会让你输密码，输的时候 **屏幕不会有任何显示**（不会出现 `***`），这是正常的安全设计，盲打完按回车就行。（①+②）

3. 查看虚拟机的 IP 地址：

```bash
# 显示网络信息，找到你的 IP 地址
ifconfig
```

4. 输出内容很多，找到类似这一行：`inet 192.168.xxx.xxx`，那一串数字就是 IP 地址。**记下来！** 例如：`192.168.126.128`
5. 验证 SSH 是否可用：回到 Windows，按 `Win + R`，输入 `cmd` 回车，打开命令提示符，输入：

```bash
# 用 SSH 连接你的虚拟机。把 用户名 和 IP 换成你自己的
ssh 你的用户名@192.168.xxx.xxx
```

6. 如果提示输入密码，输入 Ubuntu 里的密码并回车。看到 `Welcome to Ubuntu` 之类的欢迎信息，说明成功！

> **常见坑预警**：
> - 如果提示 `connection refused`：回到 Ubuntu 终端，输入 `sudo systemctl status ssh` 看看 SSH 是否在运行。绿色 `active (running)` 才对。
> - 如果连不上，可能是 VirtualBox 网络设置问题。点 VirtualBox 的"设置" → "网络"，确认"连接方式"选的是 **"网络地址转换(NAT)"**。

### 2.6 安装增强功能（让虚拟机和 Windows 更好配合）（①）

这一步让你可以在 Windows 和虚拟机之间 **直接复制粘贴文字和文件**，非常实用。

新版 VirtualBox 通常会自动安装增强功能。如果未能自动生效，可手动安装：

```bash
# 安装 VirtualBox 增强工具包
sudo apt install -y virtualbox-guest-utils virtualbox-guest-x11

# 重启虚拟机
sudo reboot
```

重启后，你就可以在 Windows 里 `Ctrl+C` 复制文字，到 Ubuntu 里 `Ctrl+V` 粘贴了！

**方案一完成！** 你现在有了一台完整的 Ubuntu 虚拟机。

## 三、方案二：WSL2（Windows 自带，通常几分钟即可完成）（①）

> **前提**：你的 Windows 版本是 Win10（版本 2004 以上）或 Win11。怎么看？按 `Win + R`，输入 `winver` 回车，看版本号。2004 以上就没问题。

### 3.1 确认虚拟化已开启（①）

**什么是虚拟化？** 简单说就是 CPU 的一个功能，让你能在 Windows 里"套娃"运行另一个系统。大部分电脑默认开启，但部分品牌机（联想、戴尔等）可能关了。

1. 按 `Ctrl + Shift + Esc` 打开 **任务管理器**
2. 点顶部的 **"性能"** 标签页
3. 右下角找 **"虚拟化"**，看是"已启用"还是"已禁用"
4. 如果是"已启用" → 跳到第二步
5. 如果是"已禁用" → 需要进 BIOS 开启（这一步稍麻烦，但必须做）：
   - 重启电脑，开机时狂按 `F2` 或 `Del` 键（不同品牌不同，联想是 F2，惠普是 F10，戴尔是 F2）
   - 进入蓝色/灰色的 BIOS 设置界面
   - 用方向键找到 **"Configuration"** 或 **"Advanced"** 菜单
   - 找到 **"Intel Virtualization Technology"** 或 **"AMD SVM"**，改成 **"Enabled"**
   - 按 `F10` 保存并退出
   - 回到 Windows 后再看任务管理器，确认变成"已启用"

> **常见坑预警**：如果实在找不到 BIOS 里的虚拟化选项，搜索"你的电脑品牌 + 开启虚拟化"，有图文教程。

### 3.2 安装 WSL2（①）

1. 按 `Win` 键，输入 `powershell`，在搜索结果里 **右键** "Windows PowerShell" → **"以管理员身份运行"**
2. 弹出"是否允许此应用更改你的设备" → 点"是"
3. 在 PowerShell 蓝框框里，**逐行** 输入以下命令（复制一整行，右键粘贴，回车）：

```bash
# 第1条：启用"适用于 Linux 的 Windows 子系统"功能
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

# 第2条：启用"虚拟机平台"功能
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

4. 两条命令都显示"操作成功完成"后，**重启电脑**
5. 重启后，再以管理员身份打开 PowerShell，输入：

```bash
# 将 WSL 默认版本设为 WSL2（比 WSL1 快很多，完全体 Linux 内核）
wsl --set-default-version 2
```

6. 如果提示需要更新内核，按提示去 https://aka.ms/wsl2kernel 下载安装即可，装完再执行上一步。

### 3.3 安装 Ubuntu 24.04（①）

**方法一（推荐，简单）**：

1. 按 `Win` 键，输入 `Microsoft Store`，打开微软应用商店
2. 搜索框输入 `Ubuntu 24.04`
3. 找到 **"Ubuntu 24.04.x LTS"**（发布者是 Canonical Group Limited），点"安装"
4. 下载大约 500MB，装完后点"打开"

**方法二（命令行）**：

```bash
# 一条命令自动下载并安装 Ubuntu 24.04
wsl --install -d Ubuntu-24.04
```

5. 首次启动会显示 "Installing, this may take a few minutes..."，等 2~5 分钟
6. 安装完会提示设置用户名和密码：
   - 输入用户名（全英文小写，如 `zhangsan`）→ 回车
   - 输入密码 → 回车（**注意：输入密码时屏幕不会有任何显示，这是正常的！**）
   - 再输一遍密码确认 → 回车
7. 出现绿色 `用户名@计算机名:~$` 就说明成功了！

> **常见坑预警**：如果在 Microsoft Store 搜不到 Ubuntu 24.04，说明你的 Windows 版本太老了。先去"设置" → "更新和安全" → 把 Windows 更新到最新。

### 3.4 更新系统（①）

在 Ubuntu 终端（就是刚那个绿色提示符的窗口）里，逐行执行：

```bash
# 更新软件包列表（刷新一下"应用商店的货架"）
sudo apt update

# 把所有已安装的软件升级到最新版（-y 表示"所有确认都自动回答 yes"）
sudo apt upgrade -y
```

> **WSL2 需要 SSH 吗？** 不需要。WSL2 与 Windows 是紧密集成的，你直接通过 VS Code 的 Remote-WSL 插件即可开发，无需像虚拟机那样额外安装和配置 SSH。

### 3.5 验证一切正常（①）

1. 在 Ubuntu 终端里执行以下命令，看是否输出正常：

```bash
# 查看当前系统版本，应该显示 Ubuntu 24.04.x
lsb_release -a

# 查看用户名，应该是你刚才设的
whoami
```

2. 测试与 Windows 互通：

```bash
# 这行命令会用 Windows 资源管理器打开当前 Linux 目录
explorer.exe .
```

如果弹出了资源管理器窗口，说明 WSL2 和 Windows 已经无缝衔接了！

> **方案二完成！**

## 四、方案三：云服务器（阿里云轻量应用服务器）（①）

> **注意**：这个方案需要付费。学生通常可享受优惠价格（以云厂商官网当前价格为准）。如果你想有一台 24 小时在线、任何地方都能连的服务器，这是最好的选择。

### 4.1 购买服务器（①）

以 **阿里云** 为例（腾讯云、华为云流程类似）：

1. 浏览器打开：https://www.aliyun.com/
2. 右上角注册/登录（用支付宝/淘宝账号就行）
3. 顶部搜索框输入 **"轻量应用服务器"**，点进去
4. 如果你是学生，先搜 **"学生优惠"**，完成学生认证后价格更低
5. 点"立即购买"：
   - **地域**：选离你最近的（如"华东1（杭州）"、"华南1（深圳）"）
   - **镜像类型**：选 **"系统镜像"**
   - **操作系统**：选 **"Ubuntu 24.04 LTS"**
   - **套餐**：最低配 2 核 2G（仅够基础练习，不适用于大模型训练或 vLLM 部署）
   - **时长**：先买 1 个月试试
6. 点"立即购买" → 付款

### 4.2 创建普通用户（安全第一步）（①）

**为什么不能一直用 root？** `root` 是 Linux 里的"超级管理员"，权限太高，误操作可能删掉系统文件。日常操作应该用普通账户。

购买后，先通过云厂商控制台提供的 **"远程连接"** 或 **VNC** 功能（网页版终端）登录服务器，执行以下操作：

```bash
# 创建新用户（把 yourname 换成你想要的用户名，全英文小写）
adduser yourname
# 会提示设置密码，输入两次即可。其他信息（全名、电话等）全部直接回车跳过

# 给这个用户添加 sudo 权限（相当于给这个账号"管理员资格"）
usermod -aG sudo yourname
```

### 4.3 配置 SSH 密钥登录（安全第二步）（①）

**为什么优先用密钥？** 密码登录容易被暴力破解。配置 SSH 密钥后，既安全又方便。

1. 在 **Windows** 上，按 `Win + R`，输入 `cmd`，打开命令提示符
2. 执行以下命令生成密钥对：

```bash
# 生成 SSH 密钥对
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

3. 出现 `Enter file in which to save the key` → 直接按 **回车**（使用默认路径）
4. 出现 `Enter passphrase` → 直接按 **回车**（不设密码短语）
5. 出现 `Enter same passphrase again` → 再按一次 **回车**
6. 看到 randomart image，说明密钥生成成功
7. 通过云厂商的 VNC/远程连接，在服务器上创建 authorized_keys 文件：

```bash
# 切换到新创建的用户
su - yourname

# 创建 .ssh 目录
mkdir -p ~/.ssh

# 用 nano 编辑 authorized_keys（将 Windows 上生成的公钥粘贴进去）
nano ~/.ssh/authorized_keys
```

8. 在 Windows 上查看公钥内容：

```bash
type %USERPROFILE%\.ssh\id_rsa.pub
```

把输出的内容全部复制，粘贴到服务器 nano 编辑器中，然后 `Ctrl+O` 保存，`Ctrl+X` 退出。

9. 设置权限：

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

### 4.4 配置防火墙（安全第三步）（①）

现在才开放 22 端口，并且建议限制访问来源：

1. 进入云厂商的 **轻量应用服务器控制台**
2. 点 **"防火墙"** 标签页
3. 点"添加规则"：
   - 端口：22
   - 协议：TCP
   - 来源：**建议填写你自己的公网 IP**（可在浏览器搜索"IP"查看），格式如 `123.45.67.89/32`。如果 IP 不固定或不确定，可暂时填 `0.0.0.0/0`（允许所有 IP，但安全性较低）
   - 点"确定"

> **安全提醒**：不要长期通过 root + 密码的方式登录服务器。务必使用普通用户 + SSH 密钥登录。

### 4.5 从 Windows 连接服务器（①）

1. 在阿里云控制台找到你的 **"公网 IP"**（一串数字，如 `47.96.xxx.xxx`），复制下来
2. 按 `Win + R`，输入 `cmd`，打开命令提示符
3. 输入以下命令连接：

```bash
# 用普通用户和密钥连接
ssh yourname@47.96.xxx.xxx
```

4. 第一次连接会提示 "Are you sure you want to continue connecting (yes/no)?"，输入 **yes** 回车
5. 如果配置了密钥且权限正确，应该直接登录成功，无需输入密码

**方案三完成！** 现在你有一台 24 小时在线的 Ubuntu 服务器。

### 6.1 文件与目录操作：最基础也最常用（新增②）

这类命令是 Linux 操作的核心，用于导航、创建、删除、复制、移动文件 / 目录。

| 命令 | 功能说明 | 语法格式 | 实战示例 |
|---|---|---|---|
| `ls` | 列出目录下的文件 / 目录 | `ls [选项] [目录路径]` | 1. 列出当前目录：`ls` <br> 2. 详细列出（含权限、大小）：`ls -l`（简写 `ll`，Ubuntu 默认别名）<br> 3. 显示隐藏文件：`ls -a` |
| `cd` | 切换目录 | `cd 目录路径` | 1. 进入上级目录：`cd ..` <br> 2. 进入根目录：`cd /` <br> 3. 回到当前用户主目录：`cd ~` <br> 4. 进入指定目录：`cd /home/user/Documents` |
| `pwd` | 显示当前所在目录的绝对路径 | `pwd` | 示例：当前在 Documents 目录，执行后输出 `/home/user/Documents` |
| `mkdir` | 创建目录 | `mkdir [选项] 目录名` | 1. 创建单个目录：`mkdir test` <br> 2. 递归创建多级目录：`mkdir -p test/aaa/bbb` |
| `touch` | 创建空文件 | `touch 文件名` | 示例：创建 2 个空文件：`touch file1.txt file2.log` |
| `cp` | 复制文件 / 目录 | `cp [选项] 源文件/目录 目标路径` | 1. 复制文件：`cp file1.txt /home/user/Desktop` <br> 2. 复制目录（需加 -r 递归）：`cp -r test/ /home/user/Desktop` |
| `mv` | 移动文件 / 目录（或重命名） | `mv 源文件/目录 目标路径` | 1. 移动文件：`mv file1.txt test/` <br> 2. 重命名文件：`mv file1.txt newfile.txt` <br> 3. 移动并改名：`mv test/ /home/user/newtest` |
| `rm` | 删除文件 / 目录（谨慎使用！） | `rm [选项] 文件/目录` | 1. 删除文件：`rm file1.txt` <br> 2. 强制删除（不提示）：`rm -f file1.txt` <br> 3. 强制删除目录（递归）：`rm -rf test/`（⚠️ 不可恢复，避免误删系统文件） |
| `cat` | 查看文件内容（适合小文件） | `cat 文件名` | 示例：查看文件内容并显示行号：`cat -n file1.txt` |
| `more/less` | 分页查看文件内容（适合大文件） | `more 文件名` / `less 文件名` | 示例：查看大日志文件：`less app.log` <br> 操作：空格翻页、回车换行、`q` 退出 |

### 6.2 权限管理：Linux 系统的安全核心（新增②）

Linux 中每个文件 / 目录都有「所有者、所属组、其他用户」三类权限，权限分为「读（r=4）、写（w=2）、执行（x=1）」。

| 命令 | 功能说明 | 语法格式 | 实战示例 |
|---|---|---|---|
| `chmod` | 修改文件 / 目录权限 | `chmod [权限值] 文件名` 或 `chmod [用户+/-权限] 文件名` | 1. 数字法（推荐）：给所有者读+写+执行，其他只读：`chmod 744 file1.txt`（7=4+2+1，4=4）<br> 2. 符号法：给所属组添加写权限：`chmod g+w file1.txt` <br> 3. 给所有用户添加执行权限：`chmod a+x test.sh` |
| `chown` | 修改文件 / 目录的所有者（需 root 权限） | `chown [用户] 文件名` | 示例：将文件所有者改为 root：`sudo chown root file1.txt`（sudo 获取临时管理员权限）|

> **sudo 回顾**：前面安装环境时你已经用过 `sudo`。它表示"以管理员身份执行"，是权限管理中最常用的前缀。输入 `sudo` 命令后会让你输密码，输的时候 **屏幕不会有任何显示**，这是正常的安全设计。（①+②）

### 6.3 系统查询：了解 Linux 运行状态（新增②）

| `top` | 实时查看系统进程和资源占用（类似 Windows 任务管理器） | `top` | 操作：按 `P` 按 CPU 占用排序、按 `M` 按内存占用排序、`q` 退出 |
| `ps` | 查看当前用户的进程 | `ps [选项]` | 查看所有进程（常用）：`ps -ef` 或 `ps aux` <br> 过滤特定进程（如查找 python 进程）：`ps -ef \| grep python` |
| `df` | 查看磁盘空间使用情况 | `df [选项]` | 以人类可读格式显示（GB/MB）：`df -h` |
| `free` | 查看内存使用情况 | `free [选项]` | 以人类可读格式显示：`free -h`（输出总内存、已用、空闲、缓存等）|

### 6.7 新手避坑指南（新增②）

**1. 区分大小写**：Linux 命令严格区分大小写！比如 `ls` 是正确的，`LS` 会报错。

**2. 路径问题**：切换目录、复制文件时，路径写错会提示 "No such file or directory"，可先用 `ls` 查看路径是否存在。

**3. rm 命令慎用**：`rm -rf` 是"删库跑路"级别的危险命令，删除前务必用 `ls` 确认目录 / 文件正确，避免误删 `/`（根目录）。

**4. 权限不足**：操作系统文件或其他用户的文件时，会提示 "Permission denied"，在命令前加 `sudo` 获取临时管理员权限（需输入当前用户密码）。

**5. 命令记不住？**：输入命令前按 `Tab` 键自动补全（文件 / 目录名）；忘记命令语法时，用 `命令 --help` 查看帮助（如 `ls --help`），或 `man 命令` 查看详细手册（如 `man cp`）。

| WSL2 报错"请启用虚拟机平台" | 虚拟化没开或 WSL 没装好 | 按方案二第一步检查虚拟化；管理员 PowerShell 执行 `wsl --update` |
| `ssh: connect to host xxx port 22: Connection refused` | SSH 服务没启动 | 在 Ubuntu 里输入 `sudo systemctl start ssh` 启动 SSH 服务 |
| `Permission denied, please try again` | 密码输错了 | Linux 密码输入不会有任何显示（连 `***` 都没有），仔细输，注意大小写 |
| VS Code 连上后代码没有高亮 | 对应语言插件没装 | 按 `Ctrl+Shift+X` 打开扩展面板，确认相关插件已安装 |
| 终端里中文显示乱码 | 字符编码问题 | 输入 `export LANG=en_US.UTF-8` 回车，或者换英文提示更省事 |
| `sudo apt update` 很慢 | 默认软件源在国外 | 搜"Ubuntu 24.04 换阿里云源"，按教程把下载源换成国内的 |
| 提示 `command not found: ifconfig` | net-tools 未安装 | 执行 `sudo apt install net-tools` |
| 误用 `rm -rf` 删错文件 | 命令太危险且无回收站 | 删除前先用 `ls` 确认；重要数据定期备份 |
