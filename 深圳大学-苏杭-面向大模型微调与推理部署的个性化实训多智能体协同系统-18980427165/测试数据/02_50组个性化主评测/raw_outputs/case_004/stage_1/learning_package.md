## 2.5 安装 SSH 远程连接工具

**SSH 是什么？** 一句话：远程桌面的“命令行版”。装好之后，你留在 Windows 终端里敲命令，就能直接操控虚拟机里的 Ubuntu，不用在两个窗口间来回切换——这对你后面在服务器上跑 vLLM 部署是必备技能。

### 操作步骤

**第 1 步：打开 Ubuntu 终端**

在 Ubuntu 桌面空白处点**鼠标右键** → 选**“在终端中打开”**。如果右键菜单里没有，按 `Ctrl + Alt + T` 也能打开。

**第 2 步：安装 SSH 服务**

依次输入以下命令（每输完一行按回车）：

```bash
# 刷新软件列表（相当于“刷新应用商店货架”）
sudo apt update

# 安装 SSH 服务端 + 网络工具（后者用来查 IP）
sudo apt install -y openssh-server net-tools

# 设置 SSH 开机自启
sudo systemctl enable ssh

# 立即启动 SSH
sudo systemctl start ssh
```

> **sudo 是什么？** 相当于“以管理员身份执行”。Linux 里普通用户不能随便装软件，加 `sudo` 就是申请最高权限。输入后会让你输密码，**屏幕不会有任何显示**（不会出现 `***`），这是正常的安全设计，盲打完按回车即可。

**第 3 步：查看虚拟机 IP**

```bash
ifconfig
```

输出内容很多，找到类似 `inet 192.168.xxx.xxx` 的那一行，后面那串数字就是 IP 地址。**记下来！** 例如：`192.168.126.128`

**第 4 步：从 Windows 验证连接**

回到 Windows，按 `Win + R`，输入 `cmd` 回车，打开命令提示符，输入：

```bash
ssh 你的用户名@192.168.xxx.xxx
```

> **如何获取用户名？** 在 Ubuntu 终端中执行 `whoami` 命令即可显示当前用户名，或者使用安装 Ubuntu 时设置的用户名。

提示输入密码就输 Ubuntu 的密码。看到 `Welcome to Ubuntu` 之类的欢迎信息，说明连接成功！

## 4.3 配置 SSH 密钥登录（安全第二步）

**为什么先做这个？** 你的目标是部署 vLLM，之后要反复 SSH 连服务器跑模型。用密码登录容易被暴力破解，配置密钥后既安全又省去每次输密码的麻烦——一次配置，长期受益。

**操作步骤（Windows 本地 → 云服务器）：**

1. **生成密钥对**：按 `Win + R` 输入 `cmd` 打开命令提示符，执行：
```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```
2. **一路回车**：出现 `Enter file...` 直接回车（用默认路径）；出现 `Enter passphrase` 再回车两次（不设密码短语）。看到 randomart image 即生成成功。
3. **查看公钥**：在 Windows 上执行 `type %USERPROFILE%\.ssh\id_rsa.pub`，复制全部输出。
4. **登录服务器**：通过云厂商的 VNC/远程连接进入服务器，执行：
```bash
su - yourname
mkdir -p ~/.ssh
nano ~/.ssh/authorized_keys
```
5. **粘贴公钥**：将复制的公钥粘贴到 nano 编辑器中，`Ctrl+O` 保存，`Ctrl+X` 退出。
6. **设置权限**：

## 新手避坑指南（重点看前 3 条）

**1. 区分文件和文件夹**：`ls -l` 第一列是 `d` 表示文件夹，是 `-` 表示文件。对文件夹操作别忘了 `-r`（如 `cp -r`、`rm -r`）。

**2. 路径写错**：切换目录或复制文件时，路径写错会提示 "No such file or directory"，可先用 `pwd` 和 `ls` 确认当前位置和目录内容。

**3. 路径中包含空格必须用引号包裹**：如果文件夹或文件名包含空格，命令行会把它当成多个参数。务必用双引号包裹：

```bash

# 正确：
mkdir "my folder"
cd "my folder"
touch "my file.txt"
cp "my file.txt" ./backup/
rm "my file.txt"
```
