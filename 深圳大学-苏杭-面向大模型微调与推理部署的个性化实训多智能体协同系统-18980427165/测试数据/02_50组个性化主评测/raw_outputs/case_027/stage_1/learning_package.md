你平时用的 Windows 或 macOS 叫“操作系统”，Linux 是另一个操作系统。全世界绝大多数服务器（网站后台、云服务、AI 训练集群）跑的都是 Linux。你之后要部署 vLLM 服务，大概率要和它打交道。

### 安装 SSH 远程连接工具：让 Windows 直接指挥 Ubuntu

你已经掌握 PyTorch 和 Transformer，接下来要部署 vLLM 服务。vLLM 是一个高效的模型推理服务，通常跑在 Linux 环境里。你现在用虚拟机装好了 Ubuntu，但来回切换窗口操作很麻烦。SSH 就是解决这个问题的——它相当于“远程桌面命令行版”，装好之后，你留在 Windows 终端里敲命令，就能直接操控虚拟机里的 Ubuntu。

**动手操作：**

1. **打开 Ubuntu 终端**：在桌面空白处点鼠标右键 → 选“在终端中打开”。如果右键没有，按 `Ctrl + Alt + T` 也能打开。

2. **安装 SSH 服务**：依次输入以下命令（输完一行按回车）：
   ```bash
   # 第1步：更新软件列表（类似“刷新应用商店的货架”）
   sudo apt update
   
   # 第2步：安装 SSH 服务端和网络工具
   sudo apt install -y openssh-server net-tools
   
   # 第3步：设置 SSH 开机自动启动
   sudo systemctl enable ssh
   
   # 第4步：立刻启动 SSH 服务
   sudo systemctl start ssh
   ```

   > **sudo 是什么？** `sudo` = “以管理员身份执行”。Linux 里普通用户不能随便装软件，加了 sudo 相当于“给我最高权限”。输入 sudo 命令后会让你输密码，输的时候**屏幕不会有任何显示**（不会出现 `***`），这是正常的安全设计，盲打完按回车就行。

3. **查看虚拟机 IP 地址**：
   ```bash
   ifconfig
   ```

4. 输出内容很多，找到类似这一行：`inet 192.168.xxx.xxx`，那一串数字就是 IP 地址。**记下来！** 例如：`192.168.126.128`

5. **获取用户名并验证 SSH**：在 Ubuntu 终端输入 `whoami` 回车，显示的就是你的用户名。回到 Windows，按 `Win + R`，输入 `cmd` 回车，打开命令提示符，输入：
   ```bash
   ssh 用户名@192.168.xxx.xxx
   ```
   例如：`ssh ubuntu@192.168.126.128`

### 4.3 配置 SSH 密钥登录（安全第二步）

你要在云服务器上跑 vLLM，这台服务器就是你的“远程工作站”。用密码登录容易被暴力破解，所以咱们先配好 SSH 密钥——相当于给服务器配一把专属钥匙，既安全又省去每次输密码的麻烦。

**在 Windows 上生成密钥对：**

1. 按 `Win + R`，输入 `cmd`，打开命令提示符。
2. 执行下面命令，生成一对密钥（公钥+私钥）：

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

3. 提示 `Enter file in which to save the key` → 直接按 **回车**（用默认路径）。
4. 提示 `Enter passphrase` → 直接按 **回车**（不设密码短语）。
5. 提示 `Enter same passphrase again` → 再按一次 **回车**。
6. 看到 randomart image（一串字符图案），说明密钥生成成功。

## mv：移动与重命名

`mv` 命令既能移动文件/文件夹，也能重命名——本质上，重命名就是在同一目录下“移动”。

**移动文件或文件夹：**

```bash
# 把文件移动到另一个文件夹
mv hello.py ./backup/

# 把文件夹移动到另一个位置
mv myproject ./archive/

# 用通配符批量移动（把所有 data_ 开头的文件移到 data 文件夹）
mv data_* ./data/
```

**重命名（同一目录下移动）：**

```bash
# 把 a.txt 重命名为 b.txt
mv a.txt b.txt

# 移动的同时改名
mv hello.py ./backup/hello_v2.py
```

**安全选项：**

```bash
# 覆盖前询问（推荐日常使用）
mv -i old.txt new.txt

# 强制覆盖，不提示（慎用）
mv -f old.txt new.txt
```

## rm：删除文件与目录

`rm` = **R**e**m**ove，删除文件或文件夹。**此命令不可逆，请谨慎使用！**

```bash
# 删除单个文件
rm hello.py

# 删除多个文件
rm file1.txt file2.txt

# 删除以 - 开头的文件（-- 告诉 rm 后面是文件名而非选项）
rm -- -file.txt

# 删除文件夹（必须加 -r，递归删除其中所有内容）
rm -r myproject/

# 只删除空文件夹
rm -d empty_dir/

# 强制删除，不提示确认
rm -f hello.py

# 强制递归删除文件夹及其中所有内容（⚠️ 极度危险，务必确认路径！）
rm -rf myproject/
```

> **⚠️ 生命警告**：`rm -rf /` 会删除整个系统！`rm -rf ~` 会删除家目录！
