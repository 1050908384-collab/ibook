### 1.1 什么是 Linux？我为什么要装它？

你平时用的 Windows 或 macOS 叫“操作系统”，Linux 是另一个操作系统。全世界绝大多数服务器（网站后台、云服务、AI 训练集群）跑的都是 Linux。学编程到后面，你大概率要和它打交道。

本教程用的是 **Ubuntu 24.04 LTS**（长期支持版），厂家会持续提供多年安全更新，稳定且适合入门。如果你已安装 Ubuntu 22.04，后续步骤同样适用。

**给你的实操建议**：  
- 如果你有云服务器（如阿里云、腾讯云），直接 SSH 登录即可，跳过本地安装。

- 虚拟机（如 VMware）适合需要图形界面的场景，但更吃内存，12GB 显存的机器建议优先 WSL2

## 块 8

### 2.5 安装 SSH 远程连接工具

**为什么这步和你的 vLLM 部署有关？**  
你的目标是量化后部署 vLLM，而 vLLM 的推理服务通常跑在 Linux 环境里。SSH 装好后，你就能在 Windows 终端里直接操控 Ubuntu，后续在服务器上跑 vLLM、看日志、传模型，全靠这个通道。

**动手做：4 步装好 SSH**

1. **打开终端**  
   在 Ubuntu 桌面空白处点**鼠标右键** → 选 **"在终端中打开"**。如果右键没有，按 `Ctrl + Alt + T` 也行。

2. **安装 SSH 服务**（输完一行按回车）

```bash
# 第1步：更新软件列表（相当于刷新应用商店）
sudo apt update

# 第2步：安装 SSH 服务端和网络工具
#     openssh-server：让别的电脑能远程连过来
#     net-tools：提供 ifconfig 命令，用来查 IP
sudo apt install -y openssh-server net-tools

# 第3步：设置开机自启
sudo systemctl enable ssh

# 第4步：立刻启动 SSH
sudo systemctl start ssh
```

> **sudo 是什么？** 就是"以管理员身份执行"。Linux 里装软件需要最高权限，加了 sudo 会提示输密码。**输密码时屏幕没有任何显示**（不会出现 `***`），这是正常的，盲打完按回车就行。

3. **查虚拟机的 IP 地址**

```bash
ifconfig
```

4. 输出内容很多，找到 `inet 192.168.xxx.xxx` 那一行，**记下这串数字**。例如：`192.168.126.128`

5. **验证 SSH 是否可用**  
   回到 Windows，按 `Win + R`，输入 `cmd` 回车，打开命令提示符，输入：

```bash
ssh username@192.168.xxx.xxx
```

6. 把 `username` 替换成你的 Ubuntu 用户名，提示输入密码就输 Ubuntu 的密码，看到 `Welcome to Ubuntu` 就说明成功了。

### 安装增强功能：让虚拟机和 Windows 更好配合

这一步的目标很直接：**让 Windows 和 Ubuntu 虚拟机之间能直接复制粘贴文字和文件**。对你要做的 vLLM 部署来说，这意味着你可以把训练好的模型代码、配置文件从 Windows 直接拖进虚拟机，省去手动传文件的麻烦。

新版 VirtualBox 通常会自动装好增强功能。如果没生效，手动装一下：

```bash
# 挂载增强功能 ISO 并运行安装脚本
sudo mount /dev/cdrom /mnt && cd /mnt && sudo ./VBoxLinuxAdditions.run

# 重启虚拟机
sudo reboot
```

重启后，在 Windows 里 `Ctrl+C` 复制，到 Ubuntu 里 `Ctrl+V` 粘贴即可。

**方案一完成！** 你现在有了一台完整的 Ubuntu 虚拟机。

Linux 中每个文件/目录都有三类权限归属：**所有者**、**所属组**、**其他用户**。权限本身有三种：读（r=4）、写（w=2）、执行（x=1）。数字是权限的简写，比如 7 = 4+2+1 表示读写执行全开。

**chmod** 修改权限，两种用法：
- 数字法（推荐）：`chmod 744 file1.txt` 表示所有者有全部权限（7），其他用户只读（4）。
- 符号法：`chmod g+w file1.txt` 给所属组加写权限；`chmod a+x test.sh` 给所有用户加执行权限。

**chown** 修改所有者，需要 root 权限：`sudo chown root file1.txt`。`sudo` 是临时管理员身份，输密码时屏幕无显示是正常的安全设计
