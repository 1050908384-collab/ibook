## 1. 本章写作目标

说明学习者在界面中能够实际完成的流程和看到的状态，不将设计建议当作现成功能。

## 2. 代码证据

- 页面：`frontend/src/pages/OnboardingPage.tsx`、`ProfileConfirmPage.tsx`、`ChatPage.tsx`、`Dashboard.tsx`、`SettingsPage.tsx`。
- Agent 状态：`frontend/src/utils/agentFlowState.ts`。
- 知识网络：`frontend/src/utils/knowledgeNetworkLayout.ts`、`frontend/src/data/knowledgeGraph.ts`。

## 3. 可直接放入方案书的正式文本

系统前端围绕“创建学习目标—确认画像—开始当前阶段—阅读与答疑—阶段测试—查看结果—规划下一阶段”的连续任务设计。入门页面收集目标、基础、学习时长、偏好和硬件等信息；画像确认页面展示诊断结果及当前阶段；学习工作台提供学习包阅读、阶段内问答和测试入口；结果视图呈现正确率、阶段总结和下一步操作；仪表盘与设置页面支持查看学习项目、进度、画像和相关配置。

为避免协同过程成为完全不可见的后台黑盒，前端维护四个正式 Agent 的待执行、运行、完成和失败状态，并在学习过程展示当前协同进度。知识网络以板块和知识点呈现学习范围，学习路径与当前阶段结合，使学习者能够理解当前学习内容在整体知识体系中的位置。阶段测评采用独立测评尝试和答题提交机制；结果页面基于后端保存的阶段结果恢复展示，避免刷新页面后丢失已完成阶段信息。

前端页面与交互已完成手工验收；核心后端与编排逻辑采用 Python `unittest` 测试。前端浏览器自动化测试尚未建设，列入后续工作。

## 5. 方案书正式正文

## 七、用户体验与可视化呈现

用户体验是系统价值的最终呈现方式。作品不仅关注后端的Agent协同和内容质量，也重视前端的交互设计和可视化效果，让学习者能够直观地看到自己的学习状态、Agent的工作过程和知识体系的全貌。

### 7.1 学习画像与诊断结果呈现

系统以画像卡片的形式呈现学习者的学情诊断结果，包含已有基础、知识盲区、学习目标、每日时长、学习风格、硬件条件和画像置信度等核心信息。

画像呈现的设计理念是"可确认、可调整"——学习者看到诊断结果后，可以判断系统是否理解正确，如果有偏差可以补充或修改。画像不是一次性的"贴标签"，而是一个可以持续校准的动态模型。

诊断结果同时会展示当前阶段的信息，包括阶段主题、预计学习时长、建议天数和规划理由。规划理由帮助学习者理解"为什么现在学这个知识点"，让学习路径变得透明和可解释，而不是一个黑盒式的安排。

### 7.2 Agent协同状态可视化

系统在学习包生成期间提供基于运行事件的协同进度展示。前端生成进度弹窗会轮询后端事件流，按时间顺序呈现资源生成、专业审核、意见回复、修订和复核等关键事件；整体Agent流程图则用于展示四个运行时Agent的固定职责与协作顺序，是架构视图而不是逐Agent实时状态机。

学习者可以看到当前系统正在执行什么——是诊断规划、资源生成、审核修订还是阶段决策，而不是面对一个完全黑盒的等待页面。这种"过程可见"的设计降低了学习者的不确定感，也直观展示了多Agent协同的工作方式。

Agent协同状态可视化不仅是用户体验的需要，也是作品技术展示的重要窗口——通过固定职责流程图与运行事件日志，评委和用户可以直观地理解四个Agent如何协作完成学习任务。

### 7.3 知识网络与学习路径可视化

知识网络可视化是系统的特色功能之一。学习者可以在知识网络中看到：

- 当前目标知识点的位置；
- 已掌握的节点（标记为完成状态）；
- 学习中的节点（标记为进行中状态）；
- 未解锁的节点（灰色或隐藏）；
- 硬前置和关联关系的连线；
- 当前阶段在整体知识体系中的位置。

知识网络以图形化的方式呈现了学习的"地形图"，让学习者不仅知道"我现在在哪里"，也能看到"我从哪里来、要到哪里去、路上还有什么"。这种全局视野有助于学习者建立结构化的知识体系，而不是零散地学习孤立的知识点。

学习路径可视化则以时间线或进度条的形式，展示学习者已经完成的阶段、当前正在进行的阶段和后续可选的方向。每个阶段标注正确率和使用的策略，让学习轨迹一目了然。

### 7.4 学习资源与交互体验

学习包以结构化的方式呈现，包含教程、实训代码、分阶实操指南和阶段测试题四个部分。代码块支持语法高亮和一键复制，方便学习者在自己的环境中实操。内容来源和审核状态也会标注，让学习者了解内容的可靠性。

实时答疑采用对话式交互。学习者可以在学习过程中随时提问，系统结合当前阶段的上下文给出回答。回答的审核状态会显示——"已通过技术审核""已通过质量审核"等标记增强了学习者对回答质量的信任感。

阶段测试提供即时反馈。客观题提交后立即判分并给出正确答案和解析；测试完成后显示阶段正确率和错题分布。学习者不需要等待教师批改就能知道自己的掌握情况，并可以根据错题立即回顾相关知识点。

整体交互设计遵循"学习为中心"的原则——界面服务于学习，不喧宾夺主。核心学习内容占据主要视觉区域，辅助信息（Agent状态、知识网络等）合理分布在侧边或可展开的面板中，既提供必要的上下文，又不干扰学习的专注度。
