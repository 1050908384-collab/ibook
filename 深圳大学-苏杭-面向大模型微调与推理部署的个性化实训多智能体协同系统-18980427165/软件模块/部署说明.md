# 部署说明

本说明适用于 Windows 10/11 评审环境。请保留提交包原有目录层级，不要单独移动“源代码”或“一键运行（可执行程序）”目录。

## 1. 交付目录

```text
软件模块/
├─ 部署说明.md
├─ 源代码/                         # 可运行项目根目录
│  ├─ backend/                     # FastAPI 后端及多 Agent
│  │  ├─ .env                      # 模型、端口和数据库配置；评委填写自己的 API Key
│  │  └─ .env.example              # 无真实密钥的配置模板
│  ├─ frontend/                    # React 前端
│  │  ├─ .env.local                # 前端 API/预览模式配置
│  │  ├─ .env.example              # 前端配置模板
│  │  ├─ package.json              # 前端依赖与 npm 命令
│  │  ├─ package-lock.json         # 前端依赖锁定版本
│  │  └─ tests/                    # 前端状态流、知识图谱和阶段操作测试
│  ├─ scripts/                     # 初始化、构图和评测脚本
│  ├─ tests/                       # 后端单元测试与多 Agent 协同验收测试
│  ├─ data/                        # 首次初始化所需运行数据
│  │  ├─ seeds/                    # 知识块、知识点、题库和图谱关系种子
│  │  ├─ 知识库原始数据/           # 73 个知识点的 Markdown 学习资料
│  │  └─ knowledge_base/           # 视频资源映射
│  ├─ requirements.txt             # Python 依赖清单
│  ├─ README.md                    # 项目功能与接口说明
│  ├─ .gitignore                   # 密钥、缓存、构建产物忽略规则
│  └─ .gitattributes               # 仓库属性配置
└─ 一键运行（可执行程序）/
   ├─ 一键启动.bat                 # 日常启动入口
   ├─ _launcher.ps1                # 启动实现，不要单独删除或移动
   ├─ 清理个人数据.bat             # 清理演示账户数据的入口
   └─ _clean_personal.ps1          # 清理实现，不要单独删除或移动
```

`一键启动.bat` 会固定启动同级的 `源代码` 目录。桌面快捷方式不是交付必需项。

## 2. 运行前准备

首次运行前，请安装以下软件并重新打开 CMD，使其进入系统 `PATH`：

| 软件 | 版本或用途 | 验证命令 |
|---|---|---|
| Python | 3.12+，运行后端和初始化脚本 | `python --version` |
| Node.js | 18+，安装并运行前端 | `node --version` 和 `npm --version` |
| Ollama | 本地模型服务与向量嵌入 | `ollama --version` |
| DeepSeek API Key | 推荐，用于云端内容生成 | 在 `backend/.env` 配置 |

Ollama 为首次初始化所必需：系统要用 `qwen3-embedding:0.6b` 构建知识库向量索引。即使填写 DeepSeek API Key，也请安装 Ollama 和该嵌入模型。

建议使用 DeepSeek 作为主模型、Ollama 作为本地回退。未配置 DeepSeek API Key 时，系统会使用本地 Ollama 模型，但本机需要具备相应算力。

## 3. 配置模型

打开 CMD，进入源码根目录。请将下面的路径替换为解压后实际路径：

```cmd
cd /d "<提交包根目录>\软件模块\源代码"
notepad backend\.env
```

找到并替换以下行中的占位符，保存后关闭记事本：

```env
DEEPSEEK_API_KEY=your-deepseek-api-key
```

保留以下默认配置即可：

```env
LLM_PROVIDER=deepseek
LLM_FALLBACK_PROVIDER=ollama
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=deepseek-r1:7b
EMBEDDING_MODEL=qwen3-embedding:0.6b
```

请勿将真实 API Key 写入 `.env.example`、README、代码或测试日志。`frontend/.env.local` 已设置 `VITE_UI_PREVIEW=false`，前后端在同一台电脑时无需修改；若前端和后端部署在不同机器，再设置 `VITE_API_BASE_URL=http://<后端IP>:8500/api/v1`。

## 4. 首次安装依赖

以下命令均在 CMD 中执行。先进入源码根目录：

```cmd
cd /d "<提交包根目录>\软件模块\源代码"
```

创建并激活 Python 虚拟环境：

```cmd
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

安装前端依赖：

```cmd
cd frontend
npm ci
cd ..
```

`npm ci` 就是本项目必需的前端依赖安装命令：它会严格按照 `package-lock.json` 安装锁定版本，比 `npm install` 更适合比赛复现。请执行 `npm ci`，不需要再额外执行 `npm install`。`npm run dev` 只负责在依赖已安装后启动前端。

下载本地模型。首次下载需要网络连接，模型文件较大，请等待命令完成：

```cmd
ollama pull qwen3-embedding:0.6b
ollama pull deepseek-r1:7b
```

若已配置有效的 DeepSeek API Key，`deepseek-r1:7b` 主要用于云端故障时自动回退；若只需云端运行且不需要回退，可将 `LLM_FALLBACK_PROVIDER` 设为空，但仍须保留 `qwen3-embedding:0.6b` 用于首次建立向量索引。

## 5. 一键启动

完成前述准备后，双击下列文件即可：

```text
软件模块\一键运行（可执行程序）\一键启动.bat
```

也可以用 CMD 启动：

```cmd
cd /d "<提交包根目录>\软件模块\一键运行（可执行程序）"
一键启动.bat
```

启动器会执行或检查以下工作：

1. 检查 Python 依赖，缺失时按 `源代码/requirements.txt` 安装。
2. 检查 `backend/.env` 与 `frontend/.env.local`，缺失时从对应 `.env.example` 创建。
3. 首次运行时，从 `data/seeds`、`data/知识库原始数据` 和视频映射初始化 SQLite 主库、知识图谱和向量索引。
4. 启动 Ollama 服务（按配置需要时）、FastAPI 后端和 Vite 前端。
5. 服务就绪后，在浏览器应用窗口打开前端。

首次初始化可能比后续启动耗时更长。正常运行地址为：

```text
前端：http://localhost:5173
后端健康检查：http://localhost:8500/health
Ollama：http://localhost:11434
```

停止系统时，关闭启动器打开的后端、前端和 Ollama 命令窗口，再关闭浏览器应用窗口。

## 6. 手动启动（用于排错）

当一键启动输出错误时，请分别打开三个 CMD 窗口，按下面顺序执行。

窗口 1，启动 Ollama：

```cmd
ollama serve
```

窗口 2，启动后端：

```cmd
cd /d "<提交包根目录>\软件模块\源代码"
venv\Scripts\activate
cd backend
python main.py
```

窗口 3，启动前端：

```cmd
cd /d "<提交包根目录>\软件模块\源代码\frontend"
npm run dev
```

随后在浏览器访问 `http://localhost:5173`。如果后端端口被占用，可修改 `backend/.env` 的 `APP_PORT`；同时需将前端 `VITE_API_BASE_URL` 改为对应端口后重启前端。

## 8. 单元测试说明

| 测试单元 | 对应核心模块 | 代表性测试文件 | 主要验证内容 |
|---|---|---|---|

### 8.2 多智能体协同调度验收

以下测试使用临时数据库或确定性模式，重点验证真实调度链路。请在 `源代码` 根目录、已激活虚拟环境后执行：


## 10. 常见问题

| 现象 | 处理方式 |
|---|---|
| `python`、`node`、`npm` 或 `ollama` 不是内部命令 | 安装对应软件，勾选加入 PATH，关闭并重新打开 CMD。 |
| `DEEPSEEK_API_KEY` 报认证或余额错误 | 检查 Key 是否完整、账户余额和 `DEEPSEEK_API_BASE=https://api.deepseek.com`。 |
| 前端显示预览内容或不请求后端 | 检查 `frontend/.env.local` 中 `VITE_UI_PREVIEW=false`，修改后重启前端。 |
| 前端请求 `404` 或网络错误 | 访问 `http://localhost:8500/health`；确认后端已启动且端口与前端 API 地址一致。 |
| Ollama 模型不存在 | 依次运行 `ollama pull qwen3-embedding:0.6b` 和 `ollama pull deepseek-r1:7b`。 |
| `npm ci` 失败 | 删除 `frontend/node_modules` 后重新运行 `npm ci`；不要提交 `node_modules`。 |
| Python 依赖安装失败 | 确认已激活 `venv`，再执行 `python -m pip install -r requirements.txt`。 |
| 首次建库或建索引耗时较久 | 保持 Ollama 服务运行，不要关闭窗口；首次完成后后续启动会快很多。 |

## 11. 提交与安全边界

- `backend/.env` 仅保留 `your-deepseek-api-key` 占位符；评委自行填写自己的 Key。
- `node_modules`、`.npm-cache`、`dist` 和 `__pycache__` 为可再生文件，不作为源码提交。
- 本系统的公共知识库、测试数据和评测证据位于提交包的“测试数据”部分；源码目录保留了首次初始化所需的种子、知识库正文和资源映射，保证一键启动可独立完成初始化。
