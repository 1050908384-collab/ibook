========================================================================
               AI Agent Trainer  -  快捷方式 文件夹说明
========================================================================

本文件夹包含 3 个用户脚本、2 个辅助脚本 + 1 份说明。
所有脚本都已经把内部路径修正为"父目录 = 项目根目录"，
所以它们必须一直留在本文件夹里使用，不要单独拷到别处。

  =========================================================
  重要：以下两个文件不能删，是"创建/删除桌面快捷方式"的
  真正执行体。bat 只是调用它们的外壳。
     _create_shortcut.vbs
     _remove_shortcut.vbs
  =========================================================

========================================================================
文件列表
========================================================================

  一键启动.bat
      -> 日常开发 / 比赛现场，双击这个就行。
      -> 做 3 件事：
         1. 新窗口启动 Ollama serve (port 11434)
         2. 新窗口启动 Backend (port 8500)
         3. 新窗口启动 Frontend (port 5173)
         4. 确认 Ollama、后端和前端均可访问后，自动用 Edge/Chrome 的"应用模式"打开前端
            （无地址栏/工具栏，观感 = 原生桌面软件）
      -> 停止：把上面 3 个命令行窗口逐一关闭即可。

  创建桌面快捷方式.bat
      -> 在新电脑上只执行一次（演示电脑、比赛电脑）。
      -> 会在系统桌面生成一个 "AI Agent Trainer" 图标。
      -> 之后评委只需双击桌面图标，不用进项目目录找。
      -> 失败也可以手动补救：
            右键 「一键启动.bat」 -> 发送到 -> 桌面快捷方式

  删除桌面快捷方式.bat
      -> 测试/试装后想清除桌面图标时，双击即可。
      -> 同时删除「桌面」和「开始菜单\程序」两处的快捷方式。
      -> 幂等：即使没装过也不会报错，只会提示"not found"。
      -> 删除后如果图标仍显示，在桌面按 F5 刷新即可。

========================================================================
首次在一台新电脑上的流程（按顺序）
========================================================================

  [一次性准备]
  1. 确认已安装：
     - Python 3.12+
     - Node.js 18+
     - Ollama ( https://ollama.com/download )
  2. 首次配置完成后，再双击「一键启动.bat」。启动器只负责启动项目，
     不会自动创建环境、下载依赖或修改系统 PATH。手动配置命令：
       python -m venv venv
       venv\Scripts\activate
       pip install -r requirements.txt
       cd frontend
       npm ci
       cd ..
  3. 如果项目里还没有 backend\.env：
       复制 backend\.env.example 为 backend\.env
       根据本机修改端口 / 模型名（一般保持默认即可）
  4. 拉 Ollama 模型（两个都需要）：
       ollama serve   # 在独立窗口保持运行
       ollama pull deepseek-r1:7b
       ollama pull qwen3-embedding:0.6b
  5. 如果种子/数据库还没初始化：
       venv\Scripts\activate
       python scripts\init_db.py
       python scripts\sync_knowledge_catalog.py
       python scripts\build_knowledge_graph.py
       python scripts\prepare_video_resources.py
       python scripts\insert_knowledge_data.py
       python scripts\init_knowledge_base.py
       python scripts\init_agent1_semantic_index.py
       python scripts\seed_test_data.py
       python scripts\check_review_schema.py
  6. 双击 「创建桌面快捷方式.bat」 -> 桌面出现图标。

  [每天 / 演示时]
  双击桌面的 「AI Agent Trainer」 图标  (或双击「一键启动.bat」)。
  -> 脚本会等待所有服务就绪后，再弹出自带独立窗口的界面。

========================================================================
端口说明（默认值）
========================================================================

  11434  Ollama 本地大模型服务
  8500   Backend (FastAPI)
         也提供 /health 健康检查：http://localhost:8500/health
  5173   Frontend (Vite dev server)
         入口：http://localhost:5173

========================================================================
故障排查
========================================================================

  - 提示 'ollama' 不是内部或外部命令：
      安装 Ollama 或把 ollama.exe 目录加入 PATH。

  - 提示 'python' 或 'npm' 不是内部或外部命令：
      安装 Python 3.12+ / Node.js 18+ 并重开命令行。
      （如果用了 venv 但本项目 venv 不存在，先按"一次性准备"重建 venv）

  - 前端启动后界面显示 Session not found / 404：
      说明前端处于 UI 预览模式。检查 frontend\.env.local：
          VITE_UI_PREVIEW=false     （必须）
      改完后重新执行「一键启动.bat」。
      如果没有这个文件，不用创建，默认就是正常模式。

  - 弹出来的是"浏览器正常窗口"（有地址栏）不是独立窗口：
      系统里没有装 Edge 和 Chrome；装其一即可，脚本会自动检测并
      使用 --app 参数启动，观感就和原生软件一致。

  - 窗口一闪就关：
      手动进对应目录看报错。比如 backend 启动失败：
          cd backend
          ..\venv\Scripts\python.exe main.py
      把报错信息截图给维护者定位。

========================================================================
停止方式
========================================================================

  直接关闭系统弹出的 3 个命令行窗口即可：
    [1/3] Ollama Serve
    [2/3] Backend port 8500
    [3/3] Frontend port 5173

  关闭后，对应的 App 窗口（那个没有地址栏的 UI 窗口）就会显示
  "无法访问此页面"，手动关掉即可。
