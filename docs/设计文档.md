# AI Agent Trainer 设计文档

## 一、项目概述

AI Agent Trainer 是一个基于多Agent协同的个性化学习辅导系统，专注于大模型微调与推理部署领域的教学。系统通过对话式交互生成用户画像，逐阶段推送学习内容，并根据测试结果动态调整学习策略。

## 二、系统架构

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        Frontend (React)                      │
├─────────────────────────────────────────────────────────────┤
│                      API Layer (FastAPI)                     │
├─────────────────────────────────────────────────────────────┤
│                    Orchestrator (Harness)                    │
├─────────────────────────────────────────────────────────────┤
│  Agent1  Agent2  Agent3  Agent4  Agent5  Agent6             │
├─────────────────────────────────────────────────────────────┤
│                      Tools Layer                             │
├─────────────────────────────────────────────────────────────┤
│                     Skills Layer                             │
├─────────────────────────────────────────────────────────────┤
│  SQLite    Chroma    NetworkX    Ollma/DeepSeek             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Agent架构

| Agent | 名称 | 职责 | 核心功能 |
|-------|------|------|----------|
| Agent1 | 学情诊断 | 用户画像生成 | 技能提取、盲区识别、置信度计算 |
| Agent2 | 目录生成 | 阶段规划 | 盲区筛选、依赖检查、阶段生成 |
| Agent3 | 内容生成 | 学习资料生产 | 教程生成、代码示例、答疑 |
| Agent4 | 技术审核 | 技术正确性检查 | 幻觉检测、语法检查、规范验证 |
| Agent5 | 质量评审 | 教学质量评估 | 难度分析、认知负荷、风格匹配 |
| Agent6 | 阶段决策 | 画像更新与策略选择 | 正确率分析、画像更新、策略选择 |

### 2.3 数据流

```
用户输入 → Orchestrator → Agent1 → 画像
                                      ↓
                                   Agent2 → 阶段信息
                                               ↓
                                            Agent3 → 学习包
                                               ↓
                                    Agent4 + Agent5 (并行审核)
                                               ↓
                                    Orchestrator → 用户展示
                                               ↓
                                    用户问答/测试 → Agent6 → 更新画像
                                               ↓
                                            Agent1 → 新画像 → 循环
```

## 四、API设计

### 4.1 对话接口

- `POST /api/chat/` - 初始对话
- `POST /api/chat/question` - 处理用户问题

### 4.2 会话接口

- `POST /api/session/` - 创建会话
- `GET /api/session/{session_id}` - 获取会话
- `PUT /api/session/{session_id}/end` - 结束会话
- `PUT /api/session/{session_id}/abandon` - 放弃会话

### 4.3 阶段接口

- `POST /api/stage/start` - 开始阶段
- `POST /api/stage/submit-answer` - 提交答案
- `POST /api/stage/complete/{session_id}` - 完成阶段

### 4.4 可视化接口

- `GET /api/visualize/profile/{session_id}` - 获取画像数据
- `GET /api/visualize/stage/{session_id}` - 获取阶段数据
- `GET /api/visualize/progress/{session_id}` - 获取进度数据

## 五、核心流程

### 5.1 首次输入流程

1. 用户输入学习背景、目标、时长、偏好
2. Orchestrator提取原始数据
3. Agent1生成用户画像
4. 置信度检查（低于阈值则追问）
5. Agent2生成下一阶段信息
6. 前端展示画像和阶段信息

### 5.2 学习阶段流程

1. 用户点击"开始学习"
2. Agent3生成学习包V1
3. Agent4+5并行审核
4. 如有错误，Agent3修改生成V2
5. 循环直到审核通过或达到最大迭代次数
6. 展示学习包给用户

### 5.3 答疑流程

1. 用户提问
2. Agent3生成回答
3. Agent4+5审核回答
4. 通过后展示给用户
5. 记录问答历史

### 5.4 测试与迭代流程

1. 用户完成测试
2. Orchestrator计算正确率
3. Agent6分析数据，更新画像
4. Agent1生成新画像
5. Agent2生成下一阶段
6. 循环直到所有盲区掌握

## 八、部署说明
