=====================
工作流说明（辩论模式）
=====================
整体流程：
① 学情诊断 → ② 知识检索 → 【辩论循环】→ ⑤ 质量评审 → ⑥ 迭代决策

辩论循环（debate_round < 3）：
③ 内容生成 → ④ 技术审核 → 有幻觉？
    ├─ 是 → ③ 重新生成（debate_round++）
    └─ 否 → 退出辩论循环，进入⑤

终止条件：
- debate_round >= 3 且仍有幻觉 → 触发熔断，接受当前最优版本或降级处理
- iteration_round >= max_iterations → 终止，返回当前最佳版本
- 正确率 > 85% 且覆盖率 > 90% → 终止，返回最终资源
- 连续2轮迭代后指标提升 < 3% → 判定为"停滞"，终止或人工介入
