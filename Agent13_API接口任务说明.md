# Agent1/3 前端 API 接口任务说明

本文档仅覆盖 Agent1/3 队友负责的前端 API：会话、用户诊断与画像、当前阶段与学习包。

## 1. 会话与左侧对话栏

| 接口 | 用途 | 负责人 |
| --- | --- | --- |
| `POST /api/v1/sessions` | 新建一个学习目标/对话 | Agent1/3 |
| `GET /api/v1/sessions` | 左侧栏列出所有会话 | Agent1/3 |
| `GET /api/v1/sessions/{session_id}` | 获取完整会话快照，页面刷新时恢复现场 | Agent1/3 |
| `POST /api/v1/sessions/{session_id}/abandon` | 放弃当前学习 | Agent1/3 |

### 核心接口：获取会话快照

`GET /api/v1/sessions/{session_id}` 是前端最重要的接口。学习页、画像页、测试页和仪表盘均可复用该接口，只读取各自需要的字段。

返回内容：

```text
session_id
title
status
phase
profile
current_stage
next_stage
learning_package
assessment_summary
progress_summary
recent_qa
available_actions
created_at
updated_at
```

## 2. 用户填写信息与画像界面

| 接口 | 用途 | 负责人 |
| --- | --- | --- |
| `POST /api/v1/sessions/{session_id}/diagnosis/messages` | 提交首次个人情况或回答 Agent1 追问 | Agent1/3 |
| `GET /api/v1/sessions/{session_id}/diagnosis/messages` | 恢复填写/追问对话 | Agent1/3 |
| `GET /api/v1/sessions/{session_id}/profile` | 获取完整用户画像 | Agent1/3 |
| `POST /api/v1/sessions/{session_id}/profile/confirm` | 用户确认画像 | Agent1/3 |
| `PATCH /api/v1/sessions/{session_id}/profile` | 修改每日时长、风格、目标等 | Agent1/3 |

### 诊断接口返回内容

```text
status: needs_more_info | profile_ready
assistant_message
missing_fields
followup_questions
profile_draft
confidence
```

### 画像确认后的状态

```text
phase = stage_ready
available_actions = ["start_stage", "edit_profile"]
```

## 3. 当前阶段与学习包

| 接口 | 用途 | 负责人 |
| --- | --- | --- |
| `GET /api/v1/sessions/{session_id}/stages/current` | 获取当前阶段摘要 | Agent1/3 |
| `POST /api/v1/sessions/{session_id}/stages/current/start` | Agent3 生成学习包，并完成 Agent4 审核 | Agent1/3 调用流程；Agent4/6 提供审核结果结构 |
| `GET /api/v1/sessions/{session_id}/stages/current/package` | 刷新学习页面后恢复学习包 | Agent1/3 |

### 学习包返回字段

```text
stage_id
stage_num
block_name
subtopic_name
estimated_hours
tutorial
code_examples
learning_resources
questions
review_summary
```

### 学习资源 `learning_resources`

学习资源直接嵌在学习包中，不需要单独设计资源接口。

```text
resource_id
resource_type: video | article | documentation | code
title
url
description
order
```

### 公开题目约束

学习包返回给前端的 `questions` 必须是公开题目，不能包含以下字段：

```text
correct_answer
explanation
expected_output
内部判题规则
```

正确答案和解析只能在用户提交完整测试后，由 AssessmentService 的测试结果接口返回。
