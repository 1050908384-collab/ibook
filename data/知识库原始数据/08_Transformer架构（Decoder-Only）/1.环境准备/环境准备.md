## 一、安装与验证 transformers（①+②+③）

### 1.1 快速安装（①）

如果你已完成第七板块的学习，`transformers` 库应该已经安装。如果尚未安装，在已有的 `pytorch` conda 环境中执行：

安装完成后，运行以下命令验证：

```bash

```

若输出类似 `[{'label': 'POSITIVE', 'score': 0.9998}]`，说明安装成功。（①）

## 二、加载 GPT-2 模型（权威②）

GPT-2 是 OpenAI 发布的因果语言模型，有多个尺寸版本：

| 模型 | 参数量 | 大小 | 运行要求 |
|---|---|---|---|
| GPT-2 (small) | 124M | ~500MB | CPU / 4GB 内存即可 |
| GPT-2 medium | 355M | ~1.5GB | 建议 GPU，或 8GB+ 内存 |
| GPT-2 large | 774M | ~3GB | 需要 GPU |
| GPT-2 xl | 1.5B | ~6GB | 需要 GPU，显存 ≥ 8GB |

本节使用 **GPT-2 small** 进行实验，CPU 即可运行。（权威②）

### 2.1 使用 pipeline 快速体验（权威②）

`pipeline` 是 transformers 提供的高级 API，一行代码即可体验模型能力：

```python
from transformers import pipeline

# 创建文本生成 pipeline，device=-1 表示使用 CPU
generator = pipeline("text-generation", model="openai-community/gpt2", device=-1)

result = generator("Hello, I'm a language model", max_new_tokens=20)
print(result)
```

> **本地运行配置要求**：首次运行会自动从 HuggingFace Hub 下载 GPT-2 模型文件（约 500MB），需要联网。下载后缓存到本地，后续无需重复下载。CPU 即可运行，内存 ≥ 4GB。

### 2.2 手动加载 Tokenizer 和 Model（权威②）

为了观察模型内部细节，我们使用底层 API 手动加载：

```python
from transformers import AutoTokenizer, GPT2LMHeadModel

# 加载分词器
tokenizer = AutoTokenizer.from_pretrained("openai-community/gpt2")

# 加载模型
model = GPT2LMHeadModel.from_pretrained("openai-community/gpt2")

# GPT-2 默认没有 pad_token，必须手动设置（否则 batch 处理会报错）
tokenizer.pad_token = tokenizer.eos_token

print(f"词表大小: {model.config.vocab_size}")
print(f"最大序列长度: {model.config.n_positions}")
print(f"隐藏层维度: {model.config.n_embd}")
print(f"层数: {model.config.n_layer}")
print(f"注意力头数: {model.config.n_head}")
```

**输出**：（权威②）

```
词表大小: 50257
最大序列长度: 1024
隐藏层维度: 768
层数: 12
注意力头数: 12
```

> 这些参数对应了 Transformer 架构的核心超参数：`n_embd` 是隐藏层维度，`n_layer` 是 Transformer Block 的堆叠层数，`n_head` 是多头注意力中的头数。后续课程会逐一讲解这些组件的内部机制。（权威②）

## 三、前向传播实验：观察 GPT-2 的内部输出（权威②）

### 3.1 完整前向传播流程

```python
import torch

# 准备输入
text = "Hello, my dog is cute"
inputs = tokenizer(text, return_tensors="pt")

print(f"input_ids 形状: {inputs['input_ids'].shape}")
# torch.Size([1, 6]) —— batch=1, sequence_length=6

# 执行前向传播
with torch.no_grad():
    outputs = model(
        **inputs,
        output_hidden_states=True,   # 返回每层的隐藏状态
        output_attentions=True       # 返回每层的注意力权重
    )

# 观察输出
print(f"\nlogits 形状: {outputs.logits.shape}")
# torch.Size([1, 6, 50257]) —— [batch, seq_len, vocab_size]

print(f"hidden_states 数量: {len(outputs.hidden_states)}")
# 13 —— 输入嵌入层 + 12 个 Transformer 层

print(f"attentions 数量: {len(outputs.attentions)}")
# 12 —— 每层一个注意力权重矩阵
```

> **关键理解**：`logits` 的最后一个维度是 `vocab_size=50257`，表示模型对**每个位置**的**每个词**都预测了一个分数。对于语言模型训练，下一个 token 的预测就是通过这些 logits 做 Softmax 后采样得到的。（权威②）

### 3.2 观察下一词预测（权威②）

```python
# 取最后一个位置的 logits，预测下一个词
next_token_logits = outputs.logits[0, -1, :]  # 形状: [50257]
next_token_id = torch.argmax(next_token_logits).item()
next_token = tokenizer.decode(next_token_id)

print(f"模型预测的下一个词: '{next_token}'")
```

### 3.3 观察因果注意力掩码（权威②）

GPT-2 是 Decoder-Only 模型，使用**因果（causal）注意力**——每个 token 只能看到自己和之前的 token，不能看到未来的 token。我们可以通过注意力权重矩阵验证这一点：

```python
# 取第一层的注意力权重
# 形状: [batch=1, n_head=12, seq_len=6, seq_len=6]
attn = outputs.attentions[0]

# 查看第一个注意力头的权重矩阵
attn_matrix = attn[0, 0].numpy()  # 形状: [6, 6]

# 打印上三角是否接近 0（因果掩码的效果）
import numpy as np
upper_triangular = np.triu(attn_matrix, k=1)
print(f"上三角区域最大权重: {upper_triangular.max():.6f}")
# 应接近 0，证明未来位置被掩码屏蔽
```

> **因果掩码的可视化**：如果你将 `attn_matrix` 用热力图绘制，会看到一个下三角矩阵——只有左下角有值，右上角（未来位置）几乎为 0。这就是 Decoder-Only 模型的核心特征，后续"重点理解 Decoder-Only 架构"章节会深入讲解其数学原理。（权威②）

### 3.4 使用 labels 计算损失（权威②）

在训练时，语言模型的 labels 就是 input_ids 本身（模型预测下一个词，所以 labels 是 input_ids 向后偏移一位）。transformers 内部会自动处理这个偏移：

```python
# 训练模式：传入 labels 会自动计算语言建模损失
with torch.no_grad():
    outputs = model(**inputs, labels=inputs["input_ids"])

print(f"Loss: {outputs.loss.item():.4f}")
# 一个标量值，表示模型预测下一个词的交叉熵损失
```

> **注意**：`GPT2LMHeadModel` 内部已经将 labels 做了**左移一位**处理（即预测第 i 个位置的词时，目标是第 i+1 个词）。你不需要手动偏移，直接传 `labels=input_ids` 即可。（权威②）

## 四、缓存与离线配置（①）

### 4.1 模型缓存目录（①）

从 HuggingFace Hub 下载的模型默认缓存到以下位置：

- Linux/macOS: `~/.cache/huggingface/hub`
- Windows: `C:\Users\username\.cache\huggingface\hub`

可通过环境变量修改：（①）

```bash
# 方法 1：设置 HF_HOME（推荐）
export HF_HOME="/path/to/your/cache"

# 方法 2：设置 TRANSFORMERS_CACHE
export TRANSFORMERS_CACHE="/path/to/your/cache"
```

### 4.2 离线运行（①）

在防火墙或内网环境中，设置以下环境变量启用离线模式：（①）

```bash
export TRANSFORMERS_OFFLINE=1
export HF_DATASETS_OFFLINE=1
```

然后指向本地缓存目录加载模型：

```python
tokenizer = AutoTokenizer.from_pretrained("/local/path/to/gpt2")
model = GPT2LMHeadModel.from_pretrained("/local/path/to/gpt2")
```

> **预先下载模型供离线使用**：在有网环境中先用 `from_pretrained()` 下载，再用 `save_pretrained("./local/path")` 保存到指定目录。（①）

## 五、常见问题与解决（①+②+③）

| 症状 | 可能原因 | 解决方案 |
|---|---|---|
| `OSError: Can't load tokenizer` | 本地路径缺少 `tokenizer_config.json` | 确保本地目录包含完整的分词器文件（①） |
| `RuntimeError: Expected all tensors on same device` | 模型和数据不在同一设备 | 确保 `model.to(device)` 和数据 `.to(device)` 一致 |
| `GPT-2 padding 报错` | 默认没有 `pad_token` | 手动设置 `tokenizer.pad_token = tokenizer.eos_token`（权威②） |
| 下载速度极慢 | 网络问题 | 使用 `HF_HOME` 指定缓存目录，或配置镜像源（③） |
| 显存不足（OOM） | 加载了过大的模型 | 换用 GPT-2 small，或启用 `load_in_8bit=True`（权威②） |
