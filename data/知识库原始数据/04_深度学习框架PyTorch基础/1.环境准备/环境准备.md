以下步骤在前面板块已经详细学过，本节只做**快速确认**。如果某一步报错，请回到对应章节排查。

### 1.1 确认 conda 可用（conda/pip 虚拟环境管理 章节已学过）

```bash
conda --version
# 预期输出：conda 24.x.x
```

### 1.2 确认 nvidia-smi 有输出（nvidia-smi 显存监控 章节已学过）

```bash
nvidia-smi
```

- 如果有正常输出（显示显卡型号、驱动版本、CUDA Version），跳到 **第二节**。
- 如果报错 `command not found`，说明当前环境**没有识别到 NVIDIA 驱动**。请先安装驱动（见下方 **1.3 节**），或选择安装 **CPU 版 PyTorch**。

### 1.3 （如需要）安装 NVIDIA 显卡驱动

> **什么情况需要这一步？**
> - 云服务器 GPU 实例：通常**已预装驱动**，不需要操作。
> - 本地物理机（双系统 / 独立 Linux）：如果 `nvidia-smi` 报错，需要手动安装。
> - WSL2：Windows 主机的驱动会自动穿透到 WSL2，一般不需要在 WSL2 内部单独安装。

**Linux 本地物理机安装驱动**：

1. 访问 NVIDIA 官方驱动下载页面：https://www.nvidia.com/Download/index.aspx
2. 选择你的显卡型号和操作系统（Linux 64-bit），下载对应的 `.run` 文件
3. 按 NVIDIA 官方安装说明或发行版包管理器完成安装。不要直接复制执行 `.run` 安装命令；禁用 nouveau、切换图形界面等步骤依发行版而异，操作不当可能导致系统无法进入图形界面。

> 更简单的做法：Ubuntu 自带的"附加驱动"工具
> ```bash
> ubuntu-drivers devices          # 查看推荐驱动
> sudo ubuntu-drivers autoinstall # 自动安装推荐驱动
> ```
> 安装完成后重启系统，再执行 `nvidia-smi` 验证。

## 二、先搞清楚：显卡、驱动、CUDA、PyTorch 四者是什么关系？（②）

这是安装 PyTorch 最容易踩坑的地方。很多人装完后运行 `torch.cuda.is_available()`，发现返回 `False`，然后对着一堆版本号不知道哪里错了。先把四者的依赖关系搞清楚，后面每一步都有据可依。（②）

```
显卡硬件（如 RTX 4060）
    ↓ 决定支持的驱动版本上限
NVIDIA 显卡驱动（Driver）
    ↓ nvidia-smi 右上角显示的 CUDA Version = 驱动支持的最高 CUDA 版本
CUDA Toolkit（nvcc --version，可选）
    ↓ PyTorch 自带 CUDA Runtime，一般不需要单独装
PyTorch（内置 CUDA Runtime）+ cuDNN
```

**最关键的两句话**：（②）

1. **`nvidia-smi` 右上角显示的 `CUDA Version`，是驱动支持的"最高"CUDA 版本，不是你已经安装的 CUDA 版本。** 你安装的 PyTorch 的 CUDA 版本必须 **≤** 这个值。
2. **如果你只是跑 PyTorch 训练或推理，不需要单独安装 CUDA Toolkit。** PyTorch 的 wheel/conda 包里已经自带了 CUDA Runtime，装上就能用 GPU。

> 什么时候才需要单独装 CUDA Toolkit？只有你需要编译 CUDA 扩展（如 `flash-attn`、`bitsandbytes`）或使用 `nvcc` 编译自定义 CUDA 代码时。后续"参数高效微调"和"PyTorch 进阶训练技巧"章节涉及这些库时，我们会再补充安装步骤。（②）

## 四、创建 PyTorch 专用 conda 虚拟环境（①+③）

> 此步骤在"conda/pip 虚拟环境管理"章节已详细学过，此处快速执行。

```bash
# 创建名为 pytorch 的虚拟环境，Python 版本 3.10
conda create -n pytorch python=3.10 -y

# 激活环境
conda activate pytorch
```

激活成功后，命令行提示符前面会从 `(base)` 变成 `(pytorch)`。（①+③）

> **为什么选 Python 3.10？** PyTorch 2.x 对 Python 3.8~3.12 都有良好支持。3.10 是目前生态兼容性最好的版本，绝大多数深度学习库都已适配。（②）

## 五、安装 PyTorch（①+②+③）

### 5.1 有 NVIDIA GPU：安装 GPU 版 PyTorch（②+③）

**核心原则**：PyTorch 的 CUDA 版本 ≤ `nvidia-smi` 显示的 CUDA Version。（②）

**推荐做法：去 PyTorch 官网复制安装命令**（最不容易出错）：

1. 打开 PyTorch 官方安装页面：https://pytorch.org/get-started/locally/
2. 按你的实际情况选择：
   - **PyTorch Build**：Stable（推荐）
   - **Your OS**：Linux
   - **Package**：Pip（推荐，版本更灵活）
   - **Language**：Python
   - **Compute Platform**：选择你驱动支持的 CUDA 版本（≤ `nvidia-smi` 的 CUDA Version）
3. 页面会自动生成安装命令，**直接复制粘贴到终端执行**。

以 `nvidia-smi` 显示 `CUDA Version: 12.2` 为例，你可以选择 CUDA 12.1 版本的 PyTorch（因为 12.1 ≤ 12.2）：（②）

```bash
# CUDA 12.1 版本（适合驱动支持 CUDA 12.x 的用户）
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 \
    --index-url https://download.pytorch.org/whl/cu121
```

如果你的驱动支持 CUDA 11.8（较旧显卡），使用：（②）

```bash
# CUDA 11.8 版本（适合旧显卡或驱动较旧的用户）
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 \
    --index-url https://download.pytorch.org/whl/cu118
```

> **如何确定用 cu121 还是 cu118？**
> - `nvidia-smi` 显示 CUDA Version ≥ 12.1 → 用 `cu121`
> - `nvidia-smi` 显示 CUDA Version 在 11.8~12.0 之间 → 用 `cu118`
> - 不确定时，优先选 `cu121`，因为 PyTorch 2.x 对 CUDA 12.x 的支持更完善。（②）

> **需要安装历史版本？** 访问 https://pytorch.org/get-started/previous-versions/ 查看完整对照表。

**也可以用 conda 安装**（如果你更习惯 conda）：（①）

```bash
conda install pytorch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 \
    pytorch-cuda=12.1 -c pytorch -c nvidia
```

### 5.2 无 NVIDIA GPU：安装 CPU 版 PyTorch（②+③）

如果你的电脑没有 NVIDIA 显卡（如使用虚拟机、WSL2 无 GPU 穿透、或 Mac），安装 CPU 版即可正常学习 PyTorch 语法，只是训练时速度较慢。（②+③）

```bash
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 \
    --index-url https://download.pytorch.org/whl/cpu
```

> **CPU 版能学完全部课程吗？** 可以。PyTorch 的 API（张量操作、自动求导、神经网络搭建）在 CPU 和 GPU 上几乎完全一致。后续涉及大模型微调时，CPU 版会跑得很慢甚至跑不动，但学习概念和调试代码完全没问题。（②）

### 5.3 安装过程说明

PyTorch 安装包体积较大（约 2~3GB），下载需要几分钟到十几分钟，取决于网络速度。安装过程中如果看到进度条在走，耐心等待即可。（①）

> **安装太慢？** 如果你在国内网络环境下速度很慢，建议先按本章节第三节的方法配置好全局 pip 国内镜像源，然后仅指定 PyTorch 官方 wheel 仓库即可：
> ```bash
> pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 \
>     --index-url https://download.pytorch.org/whl/cu121
> ```
> 注意：PyTorch 的 CUDA 版本包必须从官方 `download.pytorch.org` 仓库下载，请勿叠加 `-i` / `--extra-index-url` 指定其他 PyPI 镜像源，否则 pip 会优先从镜像源拉到 CPU 版或版本不匹配的包，导致 `torch.cuda.is_available()` 返回 `False`。通用依赖（如 numpy）会自动走你已配置的全局镜像源）。（②）

## 六、验证安装（①+②+③）

安装完成后，必须验证 PyTorch 是否能正常导入，以及 GPU 是否可用。

### 6.1 快速验证脚本（②+③）

在终端里逐行执行：

```bash
python -c "
import torch
print('PyTorch 版本:', torch.__version__)
print('CUDA 是否可用:', torch.cuda.is_available())
if torch.cuda.is_available():
    print('PyTorch 内置 CUDA 版本:', torch.version.cuda)
    print('GPU 数量:', torch.cuda.device_count())
    print('GPU 型号:', torch.cuda.get_device_name(0))
else:
    print('当前使用 CPU 模式')
"
```

**预期输出（GPU 版）**：（③）

```
PyTorch 版本: 2.5.1+cu121
CUDA 是否可用: True
PyTorch 内置 CUDA 版本: 12.1
GPU 数量: 1
GPU 型号: NVIDIA GeForce RTX 3060
```

**预期输出（CPU 版）**：

```
PyTorch 版本: 2.5.1+cpu
CUDA 是否可用: False
当前使用 CPU 模式
```

看到以上输出，说明 PyTorch 安装成功！（③）

### 6.2 运行一个简单的张量运算（①）

进一步验证 PyTorch 核心功能是否正常：

```bash
python -c "
import torch

# 创建一个 2x3 的随机张量
x = torch.rand(2, 3)
print('CPU 张量:')
print(x)

# 如果有 GPU，把张量移到 GPU 上
if torch.cuda.is_available():
    x_gpu = x.cuda()
    print('\nGPU 张量:')
    print(x_gpu)
    print('\n张量运算结果（GPU）:')
    print(x_gpu * 2)
else:
    print('\n张量运算结果（CPU）:')
    print(x * 2)
"
```

如果能正常输出张量内容，说明 PyTorch 环境完全就绪。（①）

## 七、常见问题与解决（①+②+③）

| 症状 | 可能原因 | 解决方案 |
|---|---|---|
| `torch.cuda.is_available()` 返回 `False` | 装了 CPU 版 PyTorch | 检查 `torch.__version__` 是否含 `+cpu`，重装 GPU 版 |
| `torch.cuda.is_available()` 返回 `False` | 没有 NVIDIA 显卡或驱动未装 | 确认 `nvidia-smi` 有输出；无 GPU 则使用 CPU 版 |
| `torch.cuda.is_available()` 返回 `False` | PyTorch 的 CUDA 版本 > 驱动支持上限 | `nvidia-smi` 看 CUDA Version，重装对应低版本 PyTorch |
| 安装时报 `No matching distribution found` | Python 版本太新或太旧 | 确保 Python 3.8~3.12，推荐 3.10 |
| `conda activate pytorch` 无效 | conda 初始化问题 | 执行 `source ~/.bashrc` 或重新打开终端 |
| 多 conda 环境，A 环境能用 GPU，B 环境不行 | B 环境装了不同版本 PyTorch | 每个环境单独安装对应版本的 PyTorch |
| 提示 `libcudart.so.12: cannot open shared object file` | Linux 上 CUDA 库路径未加入环境变量 | 执行 `export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH` 并写入 `~/.bashrc`（②） |
| WSL2 里 `nvidia-smi` 正常但 PyTorch 找不到 GPU | WSL2 版本过旧 | 在 Windows PowerShell 执行 `wsl --update`（②） |

> **最重要的排查口诀**：先确认 `nvidia-smi` 有输出 → 再确认 PyTorch 版本含 `+cuXXX` 而非 `+cpu` → 最后确认 `cuXXX` ≤ `nvidia-smi` 的 CUDA Version。（②）
