## 一、训练循环的本质：一场"数据变参数"的闭环（③）

在动手写代码之前，先理解训练循环的底层逻辑。PyTorch 使用**动态计算图**：当你执行 `output = model(input)` 时，autograd 引擎会默默记录每一步操作，构建一张从输入到损失的"施工蓝图"。（③）

调用 `loss.backward()` 时，梯度就像一股水流，沿着这张蓝图**逆向**回溯，精准地计算出每个参数对损失的"责任大小"（即梯度）。最后，`optimizer.step()` 根据这份"责任报告"调整参数。（③）

整个训练循环就是不断重复这个闭环：**前向传播 → 计算损失 → 反向传播 → 更新参数**。（②+③）

## 三、准备工作：数据、模型、损失函数、优化器（①）

### 3.1 设备配置（①）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader

# 自动选择设备：有 GPU 用 GPU，否则用 CPU
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(f"当前使用设备: {device}")
```

### 3.2 数据集与 DataLoader（①）

```python
class SimpleDataset(Dataset):
    def __init__(self, data_num):
        self.x = torch.randn(data_num, 2)
        # 简单分类规则：x0 + x1 > 0 则为类别 1，否则为 0
        self.y = torch.where(self.x[:, 0] + self.x[:, 1] > 0,
                             torch.tensor(1), torch.tensor(0))

    def __len__(self):
        return len(self.x)

    def __getitem__(self, index):
        return self.x[index], self.y[index]

# 划分训练集和验证集
train_dataset = SimpleDataset(data_num=8000)
val_dataset = SimpleDataset(data_num=2000)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False)
```

> **关键细节**：`shuffle=True` 仅用于训练集，防止模型记忆样本顺序；验证集必须 `shuffle=False`，保证每轮评估结果稳定可对比。（①）

### 3.3 模型、损失函数、优化器（①）

```python
class SimpleModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 32),
            nn.ReLU(),
            nn.Linear(32, 64),
            nn.ReLU(),
            nn.Linear(64, 2)
        )

    def forward(self, x):
        return self.net(x)

model = SimpleModel().to(device)

# 损失函数与优化器（上节内容）
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

# 学习率调度器（可选但推荐）
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30, eta_min=1e-6)
```

## 四、训练阶段：train_one_epoch（①+②）

把一轮训练的逻辑封装成函数，这是工程代码的标准写法。（①）

```python
def train_one_epoch(model, loader, criterion, optimizer, device):
    model.train()           # 启用训练模式（Dropout、BatchNorm 行为切换）
    total_loss = 0.0
    correct = 0
    total = 0

    for features, labels in loader:
        features = features.to(device)
        labels = labels.to(device)

        # ===== 训练五步走 =====（②）
        # 1. 前向传播
        outputs = model(features)
        loss = criterion(outputs, labels)

        # 2. 清零梯度（必须！否则梯度会累加）
        optimizer.zero_grad()

        # 3. 反向传播（计算梯度）
        loss.backward()

        # 4. 更新参数
        optimizer.step()

        # 5. 统计指标
        total_loss += loss.item() * features.size(0)
        pred = torch.argmax(outputs, dim=1)
        correct += (pred == labels).sum().item()
        total += features.size(0)

    avg_loss = total_loss / total
    avg_acc = correct / total
    return avg_loss, avg_acc
```

> **`model.train()` 的作用**：启用 Dropout 的随机失活、BatchNorm 使用当前 batch 的统计量。如果忘记调用，Dropout 会失效，BatchNorm 会使用全局统计量，导致训练异常。（①）

## 五、验证阶段：val_one_epoch（①）

验证阶段只评估模型在陌生数据上的表现，**不更新参数**。（①）

```python
def val_one_epoch(model, loader, criterion, device):
    model.eval()            # 启用评估模式
    total_loss = 0.0
    correct = 0
    total = 0

    # 关闭梯度计算，节省显存、加速推理
    with torch.no_grad():
        for features, labels in loader:
            features = features.to(device)
            labels = labels.to(device)

            outputs = model(features)
            loss = criterion(outputs, labels)

            total_loss += loss.item() * features.size(0)
            pred = torch.argmax(outputs, dim=1)
            correct += (pred == labels).sum().item()
            total += features.size(0)

    avg_loss = total_loss / total
    avg_acc = correct / total
    return avg_loss, avg_acc
```

> **两个必须**：验证阶段必须调用 `model.eval()`，必须用 `with torch.no_grad()` 包裹。两者缺一不可，否则不仅评估结果不准，还可能因构建计算图而浪费大量显存。（①）

## 六、主训练循环：整合一切（①）

```python
EPOCHS = 30
best_val_acc = 0.0

# 用于记录指标，后续绘图
train_loss_list, val_loss_list = [], []
train_acc_list, val_acc_list = [], []

print("========= 开始训练 ==========")
for epoch in range(EPOCHS):
    # 训练一轮 + 验证一轮
    train_loss, train_acc = train_one_epoch(model, train_loader, criterion,
                                            optimizer, device)
    val_loss, val_acc = val_one_epoch(model, val_loader, criterion, device)

    # 更新学习率（如果使用调度器）
    scheduler.step()

    # 记录指标
    train_loss_list.append(train_loss)
    val_loss_list.append(val_loss)
    train_acc_list.append(train_acc)
    val_acc_list.append(val_acc)

    # 打印日志
    print(f"Epoch [{epoch+1}/{EPOCHS}]")
    print(f"  Train Loss: {train_loss:.4f} | Train Acc: {train_acc:.4f}")
    print(f"  Val   Loss: {val_loss:.4f} | Val   Acc: {val_acc:.4f}")
    print("-" * 50)

    # 保存最优模型（验证集准确率最高时）
    if val_acc > best_val_acc:
        best_val_acc = val_acc
        torch.save(model.state_dict(), "best_model.pth")
        print(f"  >>> 发现更优模型！验证准确率 {best_val_acc:.4f}，已保存")

# 保存最后一轮模型
torch.save(model.state_dict(), "last_epoch_model.pth")
print(f"\n训练结束！最高验证准确率：{best_val_acc:.4f}")
```

> **为什么用验证集指标保存模型？** 训练集指标只反映模型"见过"的数据上的表现，验证集指标才反映**泛化能力**。用验证集筛选最优模型，是防止过拟合的标准做法。（①）

## 七、加载最优模型进行推理（①）

训练完成后，加载保存的最优权重进行预测：

```python
# 新建模型实例
load_model = SimpleModel().to(device)

# 加载权重（map_location 确保 CPU/GPU 兼容）
load_model.load_state_dict(torch.load("best_model.pth", map_location=device))
load_model.eval()

# 测试预测
test_data = torch.tensor([[1.2, 0.8], [-1.1, 0.5]]).to(device)
with torch.no_grad():
    outputs = load_model(test_data)
    preds = torch.argmax(outputs, dim=1)
print("预测类别：", preds)
```

> `map_location=device` 是关键！如果在 GPU 训练、CPU 推理，不加此参数会报错。（①）

## 九、常见问题与解决（①）

| 症状 | 可能原因 | 解决方案 |
|---|---|---|
| 损失震荡严重，无法收敛 | 忘记 `optimizer.zero_grad()` | 每次 `backward()` 前必须清零梯度 |
| 验证准确率远低于训练准确率 | 过拟合 | 增大 `weight_decay`、增加数据、添加 Dropout |
| 验证阶段结果不稳定 | 忘记 `model.eval()` | 验证前务必调用 `model.eval()` |
| GPU 显存爆炸 | 验证阶段未用 `torch.no_grad()` | 验证代码必须用 `with torch.no_grad()` 包裹 |
| `RuntimeError: Expected all tensors on the same device` | 模型和数据不在同一设备 | 确保 `model.to(device)` 和数据 `.to(device)` 都执行 |
| 模型加载报错 | 直接保存整个模型 `torch.save(model)` | 改用 `state_dict` 方式保存和加载 |
| 验证集指标波动大 | `shuffle=True` | 验证集 DataLoader 必须 `shuffle=False` |
