## 一、什么是张量？（②）

在 PyTorch 中，**张量（Tensor）** 是数据的基本单位，可以把它理解为 NumPy 的 `ndarray` 的升级版。两者的核心区别在于：**张量可以在 GPU 上运行，并且支持自动求导**（这是下节的内容）。（②+④）

如果你已经熟练掌握了 NumPy，学习 PyTorch 张量会非常轻松——两者的索引、切片、广播等概念几乎完全一致。（④）

> **官方文档**：PyTorch Tensor 完整 API 参考 https://pytorch.org/docs/stable/tensors.html

## 二、张量创建与基本属性（②）

### 2.1 创建张量（②）

```python
import torch

# 从列表创建
a = torch.tensor([[1, 2], [3, 4]])

# 创建全 0 / 全 1 张量
zeros = torch.zeros((2, 3))      # 2行3列，值全为0
ones = torch.ones((3, 2))        # 3行2列，值全为1

# 随机张量
rand = torch.rand((2, 2))        # [0, 1) 均匀分布
normal = torch.randn(2, 3)        # 标准正态分布

# 整数随机张量
ints = torch.randint(0, 10, (3, 3))  # [0, 10) 范围内的整数

# 等差数列（类似 np.arange）
seq = torch.arange(0, 10, 2)     # [0, 2, 4, 6, 8]
```

### 2.2 查看张量属性（②）

```python
x = torch.randn(3, 4, dtype=torch.float32)

print(x.shape)           # torch.Size([3, 4])  ——形状
print(x.dtype)           # torch.float32        ——数据类型
print(x.ndim)            # 2                    ——维度数
print(x.device)          # cpu                  ——所在设备
```

| 属性 | 含义 | 示例值 |
|---|---|---|
| `.shape` / `.size()` | 各维度大小 | `torch.Size([3, 4])` |
| `.ndim` | 维度数 | `2` |
| `.dtype` | 数据类型 | `torch.float32` |
| `.device` | 所在设备 | `cpu` 或 `cuda:0` |

> **注意**：PyTorch 默认数据类型是 `torch.float32`。神经网络训练时通常用这个类型，但某些场景需要 `torch.long`（如分类标签）。（②）

## 三、索引与切片（①+②）

张量的索引规则与 NumPy 几乎完全一致：**先行后列**，支持整数索引、范围切片、布尔索引和列表索引。（①+②）

```python
data = torch.randint(0, 10, (4, 5))
print(data)
# tensor([[4, 2, 5, 7, 9],
#         [1, 3, 8, 6, 0],
#         [2, 9, 4, 1, 5],
#         [3, 7, 2, 8, 6]])

# 基础索引：取第 0 行
print(data[0])           # tensor([4, 2, 5, 7, 9])

# 取第 1 列（所有行的第 1 列）
print(data[:, 1])        # tensor([2, 3, 9, 7])

# 范围切片：第 0~1 行，第 2~4 列（左闭右开）
print(data[0:2, 2:4])
# tensor([[5, 7],
#         [8, 6]])

# 列表索引：取第 1 行第 2 列、第 3 行第 4 列
print(data[[1, 3], [2, 4]])   # tensor([8, 6])

# 布尔索引：取第 1 列大于 5 的所有行
print(data[data[:, 1] > 5])
# tensor([[2, 9, 4, 1, 5]])

# 步长切片：每隔一行、每隔一列取
print(data[::2, ::2])
# tensor([[4, 5, 9],
#         [2, 4, 5]])
```

> **多维张量同理**：对于形状 `(batch, channel, height, width)` 的图像张量，`data[0, :, :, :]` 取第 0 个样本的所有通道和像素。（①）

## 四、形状变换：reshape、view 与连续内存（①+③）

### 4.1 reshape：最安全的形状变换（①+②）

`reshape()` 可以改变张量的形状，**不修改数据本身**，只改变"看待数据的方式"。（①）

```python
t1 = torch.arange(12)          # 1维，12个元素
t2 = t1.reshape(3, 4)        # 变为 3行4列
print(t2.shape)               # torch.Size([3, 4])

# -1 表示自动计算该维度的大小
t3 = t1.reshape(2, -1)        # 2行6列（-1 被自动算出为 6）
print(t3.shape)               # torch.Size([2, 6])
```

> 元素总数必须一致：3×4=12，2×6=12。（①）

### 4.2 view：与 reshape 的区别（①+③）

`view()` 和 `reshape()` 功能相似，但有一个关键区别：（③）

- **`reshape()`**：无论张量是否在内存中连续，都能工作。
- **`view()`**：**要求张量内存连续**，否则报错。

```python
t1 = torch.arange(6).reshape(2, 3)
print(t1.is_contiguous())     # True

# 连续张量：view 和 reshape 都能用
t2 = t1.view(3, 2)            # ✅ 正常
t3 = t1.reshape(3, 2)         # ✅ 正常
```

### 4.3 为什么 transpose/permute 后 view 会报错？（③）

`transpose()` 和 `permute()` **不会拷贝数据**，只是改变维度的"查看方式"，因此可能导致张量在内存中不再连续。（③）

```python
t1 = torch.arange(6).reshape(2, 3)
print(t1.is_contiguous())     # True

# 转置后
t2 = t1.transpose(0, 1)
print(t2.is_contiguous())     # False  ← 不连续了！

# t2.view(6)                  # ❌ 报错！view 要求连续
t3 = t2.contiguous().view(6)  # ✅ 先调用 contiguous() 恢复连续，再 view
t4 = t2.reshape(6)            # ✅ reshape 直接就能用
```

> **建议**：不确定时用 `reshape()`，它更宽容；追求极致性能且确认连续时用 `view()`。（③）

## 五、升维与降维：squeeze 与 unsqueeze（①）

在深度学习中，经常需要调整维度数量。例如，把 `(3, 224, 224)` 的图像升为 `(1, 3, 224, 224)` 来模拟 batch 维度。（①）

```python
t1 = torch.randn(3, 1, 2, 1)
print(t1.shape)               # torch.Size([3, 1, 2, 1])

# squeeze：删除所有大小为 1 的维度
t2 = torch.squeeze(t1)
print(t2.shape)               # torch.Size([3, 2])

# squeeze(dim=1)：只删除指定维度（如果该维度大小为1）
t3 = torch.squeeze(t1, dim=1)
print(t3.shape)               # torch.Size([3, 2, 1])

# unsqueeze：在指定位置插入一个大小为 1 的维度
t4 = t2.unsqueeze(dim=0)      # 在第 0 维前插入
print(t4.shape)               # torch.Size([1, 3, 2])

t5 = t2.unsqueeze(dim=-1)     # 在最后插入（-1 表示最后一个维度）
print(t5.shape)               # torch.Size([3, 2, 1])
```

> **常见场景**：模型推理时，单张图片的形状是 `(3, 224, 224)`，需要 `unsqueeze(0)` 变成 `(1, 3, 224, 224)` 才能输入模型。（①）

## 六、维度交换：transpose 与 permute（①+③）

### 6.1 transpose：交换两个维度（①+③）

`transpose(dim0, dim1)` 用于**交换两个指定维度**，其他维度保持不变。（③）

```python
t1 = torch.randn(2, 3, 4)
print(t1.shape)               # torch.Size([2, 3, 4])

# 交换第 0 维和第 1 维
t2 = t1.transpose(0, 1)
print(t2.shape)               # torch.Size([3, 2, 4])
```

### 6.2 permute：任意重排所有维度（①+③）

`permute(dims)` 更灵活，可以一次性指定所有维度的新顺序。（③）

```python
t1 = torch.randn(2, 3, 4)
print(t1.shape)               # torch.Size([2, 3, 4])

# 新顺序：原第2维 → 新第0维，原第0维 → 新第1维，原第1维 → 新第2维
t2 = t1.permute(2, 0, 1)
print(t2.shape)               # torch.Size([4, 2, 3])
```

### 6.3 transpose vs permute 速查（③）

| 特性 | `transpose()` | `permute()` |
|---|---|---|
| 功能 | 交换两个维度 | 任意排列多个维度 |
| 参数 | 两个整数 | 维度索引序列 |
| 返回 | 视图（view） | 视图（view） |
| 内存连续 | 可能不连续 | 可能不连续 |

> **重要**：两者返回的都是"视图"（共享底层数据），且**可能导致内存不连续**。如果后续要跟 `view()`，记得先 `.contiguous()`。（③）

## 七、张量运算（②）

### 7.1 元素级运算（②）

```python
a = torch.tensor([1., 2., 3.])
b = torch.tensor([4., 5., 6.])

print(a + b)          # tensor([5., 7., 9.])
print(a * b)          # tensor([ 4., 10., 18.])
print(torch.sqrt(a))  # tensor([1., 1.4142, 1.7321])
```

### 7.2 矩阵乘法（②）

```python
A = torch.tensor([[1., 2.], [3., 4.]])
B = torch.tensor([[5., 6.], [7., 8.]])

# 矩阵乘法（等价于线性代数中的点积）
print(A @ B)                  # 推荐写法
print(torch.matmul(A, B))     # 函数写法
# tensor([[19., 22.],
#         [43., 50.]])
```

> **新手最常踩的坑**：把 `*` 当成矩阵乘法。记住：`*` 是逐元素相乘，`@` 才是矩阵乘法。（②）

### 7.3 广播机制（②）

与 NumPy 一样，PyTorch 支持广播——不同形状的张量可以自动对齐后运算。（②）

```python
a = torch.tensor([[1], [2], [3]])   # shape (3, 1)
b = torch.tensor([10, 20, 30])      # shape (3,)

# 广播后相加 => shape (3, 3)
print(a + b)
# tensor([[11, 21, 31],
#         [12, 22, 32],
#         [13, 23, 33]])
```

### 7.4 聚合统计（②）

```python
x = torch.tensor([[1., 2.], [3., 4.]])

print(x.sum())        # 10.0
print(x.mean())       # 2.5
print(x.max())        # tensor(4.)
print(x.argmax())      # 3  （最大值的索引，按展平后计算）
```

> `axis`（或 `dim`）参数与 NumPy 一致：`dim=0` 沿行压缩得列结果，`dim=1` 沿列压缩得行结果。（②）

## 八、条件筛选与数据复制（②）

### 8.1 布尔掩码（②）

```python
x = torch.tensor([1, 2, 3, 4, 5])
mask = x > 3
print(x[mask])        # tensor([4, 5])
```

### 8.2 clone：独立拷贝（②）

```python
a = torch.tensor([1, 2, 3])
b = a.clone()         # 深拷贝，不共享内存
b[0] = 100
print(a)              # tensor([1, 2, 3])  ← a 没变
```

> 默认赋值 `b = a` 是共享内存的，修改 `b` 会影响 `a`。需要独立副本时用 `.clone()`。（②）

## 九、张量与 NumPy 互转（④）

PyTorch 张量和 NumPy 数组可以无缝转换，且**默认共享内存**（修改一个，另一个也会变）。（④）

```python
import numpy as np

# Tensor → NumPy
x = torch.tensor([1, 2, 3])
y = x.numpy()
print(y)              # [1 2 3]

x.add_(1)             # 修改 Tensor（in-place 操作）
print(y)              # [2 3 4]  ← NumPy 也跟着变了！

# NumPy → Tensor
a = np.array([1, 2, 3])
b = torch.from_numpy(a)
print(b)              # tensor([1, 2, 3])

np.add(a, 1, out=a)   # 修改 NumPy
print(b)              # tensor([2, 3, 4])  ← Tensor 也跟着变了！
```

> 如果需要不共享内存的拷贝，用 `torch.tensor(numpy_array)` 而不是 `from_numpy()`。（④）

## 十、CPU 与 GPU 切换（④）

上节我们配置了 PyTorch GPU 环境，本节学习如何把张量在 CPU 和 GPU 之间移动。（④）

```python
# 判断 GPU 是否可用
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(device)         # cuda:0 或 cpu

# 在 CPU 上创建张量
x = torch.randn(3, 3)

# 移到 GPU 上
x_gpu = x.to(device)
# 或者简写：x_gpu = x.cuda()   （仅当 GPU 可用时）

# 直接在 GPU 上创建张量
y = torch.ones(3, 3, device=device)

# GPU 张量运算
z = x_gpu + y         # 两个张量必须在同一设备上才能运算
print(z.device)       # cuda:0

# 移回 CPU
z_cpu = z.to("cpu")
# 或者简写：z_cpu = z.cpu()
```

> **常见报错**：`RuntimeError: Expected all tensors to be on the same device` —— 运算时两个张量一个在 CPU、一个在 GPU。统一用 `.to(device)` 解决。（④）

## 十一、综合实战演练（①+②+④）

请在你的 Python 环境中完成以下操作：

### 场景：模拟一次图像数据的预处理流程

```python
import torch

# 1. 模拟一张 3通道 224x224 的图像数据
image = torch.randn(3, 224, 224)
print(f"原始图像形状: {image.shape}")   # torch.Size([3, 224, 224])

# 2. 升维：添加 batch 维度 → (1, 3, 224, 224)
image_batch = image.unsqueeze(0)
print(f"添加batch后: {image_batch.shape}")  # torch.Size([1, 3, 224, 224])

# 3. 维度重排：从 (B, C, H, W) 转为 (B, H, W, C) —— 某些框架需要的格式
image_nhwc = image_batch.permute(0, 2, 3, 1)
print(f"维度重排后: {image_nhwc.shape}")    # torch.Size([1, 224, 224, 3])

# 4. 归一化运算：将所有像素值缩放到 [0, 1] 并减去均值
mean = torch.tensor([0.485, 0.456, 0.406]).view(1, 1, 1, 3)
std = torch.tensor([0.229, 0.224, 0.225]).view(1, 1, 1, 3)
image_norm = (image_nhwc - mean) / std
print(f"归一化后范围: [{image_norm.min():.2f}, {image_norm.max():.2f}]")

# 5. 移回 (B, C, H, W) 并展平为 (B, C*H*W)
image_back = image_norm.permute(0, 3, 1, 2).contiguous()
image_flat = image_back.reshape(1, -1)
print(f"展平后形状: {image_flat.shape}")    # torch.Size([1, 150528])

# 6. 如果有 GPU，移到 GPU 上运行
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
image_final = image_flat.to(device)
print(f"最终设备: {image_final.device}")
```

## 十二、常见问题与解决（①+②+③+④）

| 症状 | 可能原因 | 解决方案 |
|---|---|---|
| `view()` 报错 `view size is not compatible` | 元素总数不匹配 | 确认新形状各维度乘积等于原张量元素数 |
| `view()` 报错 `use .reshape()` | 张量经过 transpose/permute 后不连续 | 用 `.contiguous().view()` 或直接用 `.reshape()` |
| `a + b` 报错 `The size of tensor a must match` | 形状不兼容且无法广播 | 检查两个张量的形状，用 `unsqueeze` 补维度 |
| `RuntimeError: Expected all tensors on the same device` | 运算时张量分别在 CPU 和 GPU 上 | 统一用 `.to(device)` |
| 修改 Tensor 后 NumPy 数组也变了 | Tensor 和 NumPy 共享内存 | 需要独立拷贝时用 `torch.tensor(numpy_array)` |
| `x.cuda()` 报错 | 没有 GPU 或 PyTorch 是 CPU 版 | 检查 `torch.cuda.is_available()`，使用 CPU 版 |
