## 二、安装 transformers 库（①）

### 2.1 标准安装（推荐）

`transformers` 库可以通过 pip 直接安装。由于我们已经在 `pytorch` 环境中装好了 PyTorch，执行以下命令即可：（①）

```bash
pip install transformers
```

> **本地运行配置要求**：此步骤需要联网下载约 200~300MB 的安装包，对电脑配置无特殊要求，CPU 即可执行。若网络较慢，可参考下方镜像源加速。

**如果网络较慢，可使用清华镜像源加速**：（②）

```bash
pip install transformers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2.2 带 PyTorch 依赖的安装（可选）

如果你是在一个**全新的空环境**中安装（非本课程场景），可以用 extras 方式一次性安装 transformers 及其 PyTorch 适配依赖：（①）

```bash
pip install 'transformers[torch]'
```

> 本课程中 PyTorch 已提前装好，直接 `pip install transformers` 即可，无需重复安装 torch。

### 2.3 使用 conda 安装（可选）

如果你更习惯 conda，也可以从 conda-forge 通道安装：（①）

```bash
conda install conda-forge::transformers
```

> **注意**：conda-forge 中的版本可能略滞后于 pip，建议优先使用 pip 安装以获得最新版本。

## 三、安装 tokenizers 库（①+②）

### 3.1 是否需要单独安装？

`tokenizers` 通常是 `transformers` 的**依赖项**，安装 `transformers` 时会**自动安装**兼容版本的 `tokenizers`，一般不需要手动单独安装。（①）

你可以验证是否已自动安装：

```bash
python -c "import tokenizers; print('tokenizers:', tokenizers.__version__)"
# 预期输出：tokenizers: 0.x.x
```

### 3.2 什么情况下需要手动安装？

如果你需要**独立使用** `tokenizers` 库（例如自定义训练一个词表），或者自动安装的版本不符合需求，可以手动指定版本：（①）

```bash
pip install tokenizers
```

> **踩坑提醒**：参考文章记录，某些旧版本 tokenizers 在特定 Python 环境下可能需要从源码编译，进而依赖 Rust 工具链。（②+③）但本课程使用的 Python 3.10 + 最新版 tokenizers 通常有预编译的 wheel 包，可直接安装，无需 Rust。

## 四、验证安装：运行你的第一个 HuggingFace 模型（①）

安装完成后，必须验证 transformers 是否能正常工作。最简单的方法是使用 `pipeline` 加载一个情感分析模型进行推理。

### 4.1 快速验证脚本（①）

在终端执行：

```bash
python -c "from transformers import pipeline; print(pipeline('sentiment-analysis')('we love you'))"
```

**预期输出**：（①）

```
[{'label': 'POSITIVE', 'score': 0.9998704791069031}]
```

> **本地运行配置要求**：首次运行此命令时，`transformers` 会自动从 HuggingFace Hub 下载一个约 300MB 的预训练模型（`distilbert-base-uncased-finetuned-sst-2-english`）到本地缓存。需要**联网**，磁盘预留约 500MB 空间，**CPU 即可运行**，无需 GPU，内存建议 ≥ 4GB。

### 4.2 查看安装版本

```bash
python -c "
import transformers
import tokenizers
print('transformers 版本:', transformers.__version__)
print('tokenizers 版本:', tokenizers.__version__)
"
```

## 五、配置模型缓存目录（①）

当你使用 `from_pretrained()` 加载模型时，transformers 会自动从 HuggingFace Hub 下载文件并缓存到本地。默认缓存路径为 `~/.cache/huggingface/hub`。如果你的系统盘空间紧张，建议修改缓存位置。（①）

### 5.1 通过环境变量配置（①）

```bash
# 临时生效（当前终端会话）
export HF_HOME="/mnt/data/huggingface"

# 永久生效（写入 ~/.bashrc）
echo 'export HF_HOME="/mnt/data/huggingface"' >> ~/.bashrc
source ~/.bashrc
```

优先级顺序（由高到低）：（①）

1. `HF_HUB_CACHE`（最优先）
2. `HF_HOME`
3. `XDG_CACHE_HOME` + `/huggingface`

> **建议**：如果你使用云服务器，建议将 `HF_HOME` 设置到数据盘（如 `/mnt/data`），避免系统盘被模型文件占满。后续"参数高效微调"和"模型推理部署"章节加载的模型体积可达数 GB 至数十 GB。

### 5.2 在 Python 代码中查看当前缓存路径（①）

```python
from transformers import utils
print(utils.default_cache_path)
```

## 六、离线模式配置（拓展）（①）

在后续实际工作中，你可能会在内网或防火墙环境中使用预训练模型。transformers 支持完全离线运行，前提是**提前下载好所需文件**。（①）

### 6.1 预先下载模型（①）

```python
from huggingface_hub import snapshot_download

# 下载整个模型仓库到指定目录
snapshot_download(repo_id="bert-base-chinese", local_dir="./bert-base-chinese")
```

### 6.2 离线加载（①）

```bash
# 方式一：设置环境变量阻止所有 HTTP 请求
HF_HUB_OFFLINE=1 python your_script.py
```

```python
# 方式二：在代码中指定只加载本地文件
from transformers import AutoModel

model = AutoModel.from_pretrained("./bert-base-chinese", local_files_only=True)
```

## 七、常见问题与解决（①+②+③+④）

| 症状 | 可能原因 | 解决方案 |
|---|---|---|
| `pip install transformers` 速度极慢或超时 | 默认源在国外 | 使用清华镜像源：`-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `No matching distribution found` | Python 版本过低或过高 | 确保 Python 3.10+（本课程使用 3.10） |
| 导入 transformers 时报 `signal` 模块错误 | transformers 版本与 Python 不兼容 | 升级 transformers 到最新版：`pip install -U transformers` |
| `tokenizers` 安装时提示需要 Rust 编译器 | 该版本无预编译 wheel，需从源码构建 | 换用 conda 安装：`conda install -c huggingface tokenizers`；或升级 pip 以获取新版预编译包 |
| `pipeline()` 首次运行卡住不动 | 从 HuggingFace Hub 下载模型，网络不通 | 检查网络；或预先使用 `snapshot_download()` 下载到本地 |
| 磁盘空间不足 | 缓存目录在系统盘，模型文件积累过多 | 设置 `HF_HOME` 到数据盘；定期清理 `~/.cache/huggingface/hub` |
| 验证脚本输出结果与预期不符 | 模型下载不完整 | 删除缓存重新下载，或设置 `local_files_only=False` 强制校验 |

> **最重要的排查口诀**：先确认 `python --version` ≥ 3.10 → 再确认 `torch.__version__` ≥ 2.4 → 最后确认 `transformers.__version__` 为最新稳定版。（①+③）
