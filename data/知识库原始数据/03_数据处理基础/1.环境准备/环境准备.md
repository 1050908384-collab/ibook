## 一、为什么需要这些库？（①）

在正式安装之前，先了解这四个库在后续学习中的角色：（①+②）

| 库名 | 作用 | 是否需要 pip 安装 | 后续用途 |
|---|---|---|---|
| **NumPy** | 科学计算基础，提供高性能多维数组 | 是 | 数组运算、张量操作（PyTorch 基础） |
| **Pandas** | 数据处理与分析，提供 DataFrame 结构 | 是 | 数据清洗、CSV/JSON 读写 |
| **Matplotlib** | 数据可视化，绘制图表 | 是 | 数据探索、训练过程可视化 |
| **re** | 正则表达式，文本模式匹配 | **否**（Python 内置） | 文本预处理、日志解析、数据清洗 |

> **注意**：`re` 是 Python **标准库**（内置模块），随 Python 一起安装，不需要额外 pip 安装。后面会单独说明。（②）

## 三、配置 pip 国内镜像源（推荐）（③）

Pandas、NumPy、Matplotlib 体积较大，从官方源下载可能很慢甚至超时。建议先配置国内镜像源。（③）

> **注意**：镜像源地址可能随时间变化，以下配置以清华源为例。如遇问题，可查阅清华镜像站最新文档或尝试阿里云/中科大源。（③）

### 3.1 临时使用（单次生效）（③）

```bash
pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.2 永久配置（推荐）（③）

```bash
# 创建/编辑 pip 配置文件
mkdir -p ~/.pip
nano ~/.pip/pip.conf
```

写入以下内容：（③）

```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
trusted-host = pypi.tuna.tsinghua.edu.cn
```

保存后，以后所有 `pip install` 都会自动走镜像源。（③）

> **其他可用国内源（备选）**：（③）
> - 阿里云：`https://mirrors.aliyun.com/pypi/simple`
> - 中科大：`https://pypi.mirrors.ustc.edu.cn/simple`

## 四、安装核心数据处理库（①+③+④）

## 五、re 库：Python 内置，无需安装（②）

`re` 是 Python 的**内置标准库**，不需要 `pip install`，直接导入即可使用。（②）

```python
import re

# 快速测试：匹配邮箱格式
text = "contact me at user@example.com"
match = re.search(r'\b[\w\.-]+@[\w\.-]+\.\w+\b', text)
print(match.group())  # 输出：user@example.com
```

> **为什么单独提 re？** 因为后续"正则表达式进行文本预处理"章节会深入使用它，但新手常误以为需要 `pip install re`，这里提前说明避免踩坑。（②）

## 七、常见问题与解决（①+③+④）

| 症状 | 可能原因 | 解决方案 |
|---|---|---|
| `pip install` 速度极慢或超时 | 未配置国内镜像源 | 按第三节配置清华/阿里云镜像源（③） |
| `pip install` 提示权限不足 | 在系统 Python 中安装 | 先激活 conda 虚拟环境，再安装（④） |
| 导入时提示 `ModuleNotFoundError` | 安装到了其他 Python 环境 | 确认 `which python` 和 `which pip` 指向同一环境（④） |
| Matplotlib 图表无法显示 | 缺少 GUI 后端（服务器常见） | 保存为图片而非显示：`plt.savefig('plot.png')`（①） |
| 安装后版本冲突 | 环境中已有旧版本 | 新建干净 conda 环境重新安装（①） |
