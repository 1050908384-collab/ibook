# 一、先理解 Hugging Face 生态工具链（参考文章③）

## 1.1 Hugging Face是什么？

Hugging Face 是目前大语言模型开发中最常用的开源生态之一。

它主要包含：

| 工具               | 作用                    |
| ---------------- | --------------------- |
| Transformers     | 加载、训练、推理Transformer模型 |
| Datasets         | 加载和处理训练数据             |
| Accelerate       | 简化单卡、多卡、混合精度训练        |
| Hugging Face Hub | 模型、数据集和代码共享平台         |

整体学习流程：

```
Tokenizer
    ↓
Transformers加载模型
    ↓
Datasets处理数据
    ↓
Accelerate优化训练
    ↓
Trainer完成微调
    ↓
LoRA / QLoRA
    ↓
部署推理
```

# 方案三：Windows原生环境

Windows也可以运行 Hugging Face 工具链。

但是需要注意：

## Windows兼容性提醒

### 1. 路径问题

Windows路径：

```
D:\huggingface_cache
```

Linux路径：

```
/data/huggingface_cache
```

设置环境变量时格式不同。

---

### 2. CUDA环境

如果使用GPU：

需要确认：

* NVIDIA驱动；
* CUDA版本；
* PyTorch CUDA版本匹配。

检查：

```bash
nvidia-smi
```

---

### 3. 推荐使用WSL2

对于大模型开发：

推荐：

```
Windows
   ↓
WSL2 Ubuntu
   ↓
Python环境
   ↓
Transformers
```

相比Windows原生环境：

* Linux兼容性更好；
* 更接近服务器环境；
* 后续DeepSpeed、vLLM支持更方便。

# 九、配置模型缓存路径（重点）

## 9.1 为什么修改缓存？

默认：

Linux：

```
~/.cache/huggingface
```

Windows：

```
C:\Users\用户名\.cache\huggingface
```

模型可能占用：

| 模型    | 空间   |
| ----- | ---- |
| GPT-2 | 几百MB |
| 7B模型  | 十几GB |
| 70B模型 | 百GB  |

建议提前修改。

---

# 十、Linux配置缓存

创建：

```bash
mkdir -p /data/huggingface_cache
```

设置：

```bash
export HF_HOME=/data/huggingface_cache
```

永久：

```bash
echo 'export HF_HOME=/data/huggingface_cache' >> ~/.bashrc

source ~/.bashrc
```

检查：

```bash
echo $HF_HOME
```

---

# 十一、Windows配置缓存

PowerShell：

```powershell
setx HF_HOME D:\huggingface_cache
```

重新打开终端。

检查：

```powershell
echo $env:HF_HOME
```

# 十三、常见问题排查

| 问题          | 原因              | 解决                             |
| ----------- | --------------- | ------------------------------ |
| Tokenizer报错 | 缺少sentencepiece | 安装 transformers[sentencepiece] |
| Windows路径错误 | 环境变量格式问题        | 检查HF_HOME                      |
| CUDA不可用     | PyTorch CUDA不匹配 | 重新安装对应版本                       |
| 模型下载慢       | 网络问题            | 配置缓存或镜像                        |
| 磁盘不足        | 模型缓存过大          | 修改HF_HOME                      |
