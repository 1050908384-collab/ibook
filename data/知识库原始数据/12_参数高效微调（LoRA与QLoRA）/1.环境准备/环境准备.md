# 一、为什么需要参数高效微调？（①②）

## 1.1 全参数微调的问题

传统大模型训练：

```text
输入数据

↓

整个模型参数更新

↓

保存完整模型
```

例如：

7B参数模型：

```text
70亿参数
```

训练时需要：

* 保存参数；
* 保存梯度；
* 保存优化器状态。

显存需求非常高。

普通消费级GPU难以完成。

---

## 1.2 参数高效微调（PEFT）

PEFT：

Parameter-Efficient Fine-Tuning

中文：

参数高效微调。

核心思想：

> 不修改整个大模型，只训练少量新增参数。

流程：

```text
原始大模型

        +
        
LoRA适配器参数

        ↓

只训练LoRA参数

        ↓

保存小规模Adapter
```

优势：

| 方式    | 训练参数      | 显存需求 |
| ----- | --------- | ---- |
| 全参数微调 | 全部参数      | 非常高  |
| LoRA  | 少量参数      | 较低   |
| QLoRA | 量化模型+LoRA | 更低   |

---

# 二、LoRA与QLoRA基础概念（①②）

## 2.1 LoRA是什么？（①）

LoRA：

Low-Rank Adaptation

低秩适配。

原模型：

```text
W
```

不更新。

新增：

```text
W + ΔW
```

其中：

```text
ΔW = A × B
```

只训练：

```text
A

B
```

两个小矩阵。

---

## 2.2 LoRA训练特点

优点：

* 参数量少；
* 训练速度快；
* 显存占用低；
* Adapter文件小。

训练完成：

保存：

```text
adapter_model

adapter_config
```

通常只有几十MB到几百MB。

---

# 三、QLoRA是什么？（①③）

## 3.1 LoRA的问题

虽然LoRA减少训练参数。

但是：

基础模型仍然需要加载。

例如：

7B模型：

FP16：

约：

```text
14GB显存
```

---

## 3.2 QLoRA解决方案

QLoRA：

Quantized LoRA

量化版LoRA。

核心：

```text
FP16模型

↓

4bit量化

↓

减少显存

↓

加载LoRA训练
```

结构：

```text
4bit基础模型

+

LoRA参数

↓

训练
```

---

## 3.3 QLoRA依赖bitsandbytes

QLoRA需要：

```text
transformers

+

peft

+

bitsandbytes

+

CUDA GPU
```

其中：

`bitsandbytes`

负责：

* 低精度量化；
* 4bit加载；
* 8bit加载。

---

# 四、环境要求

## 电脑配置批注

本章节涉及 LoRA / QLoRA 本地训练环境。

### LoRA最低配置：

CPU：

* 4核以上

内存：

* 16GB+

磁盘：

* 50GB以上

GPU：

推荐：

* NVIDIA GPU

显存：

* 最低：

  * 8GB

推荐：

* 12GB+

---

### QLoRA要求：

GPU：

必须：

* NVIDIA CUDA GPU

显存：

QLoRA 的设计目标正是**在更小的显存上微调大模型**（通过 4-bit 量化基础模型，其显存占用通常低于同规模的 LoRA 全精度加载）。具体可运行的显存下限取决于模型规模、序列长度、batch 大小与量化配置，下面的数值仅为常见 7B 级别模型的**经验参考**，请以实际运行情况为准：

参考下限：

```text
约 8~12GB（7B 级别，短序列、小 batch）
```

推荐：

```text
16GB+
```

原因：

QLoRA虽然降低显存，但是仍需要：

* 量化后的基础模型；
* LoRA参数；
* 激活值；
* batch数据。
