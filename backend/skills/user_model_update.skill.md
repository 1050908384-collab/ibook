# SKILL名称：user_model_update

## 1. 能力描述
- 功能：根据阶段数据更新用户个性化数据（画像）
- 适用场景：Agent6更新用户画像
- 前置依赖：阶段正确率、问答历史、交互数据、当前画像

## 2. 核心方法论
- 步骤1：根据正确率更新知识盲区的掌握状态
- 步骤2：从交互数据推断学习节奏
- 步骤3：从问答质量推断信心指数
- 步骤4：检测用户的困惑标记
- 步骤5：生成更新后的个性化数据

## 3. 知识/规则定义
- 规则1：正确率≥80% → 知识盲区标记为"已掌握"
- 规则2：60%≤正确率<80% → 知识盲区标记为"部分掌握"
- 规则3：正确率<60% → 知识盲区保持"未开始"或标记为"需要重点关注"
- 规则4：学习节奏根据用户完成阶段的时间推断
- 规则5：信心指数综合考虑正确率和问答质量

## 4. 输入输出规范
- 输入：阶段正确率、qa_history、interactions、当前画像
- 输出：更新后的个性化数据（knowledge_gaps、learning_rhythm、confidence_index、confusion_markers）

## 5. 异常处理
- 数据不足无法推断 → 保持原有数据，标记为"待确认"
- 数据矛盾 → 记录日志，以最新数据为准
