# SKILL名称：user_model_update

## 1. 能力描述
- 功能：定义画像字段更新规则库，明确"算出数据后怎么写入画像"，根据掌握度和策略更新用户画像
- 适用场景：Agent⑥组装画像更新数据时，为profile_update_tool提供字段映射规则
- 前置依赖：修正后掌握概率、策略标签、阶段学习时长、问答历史、交互数据

## 2. 核心方法论
- 步骤1：掌握度→盲区状态映射——根据掌握概率更新knowledge_gaps状态
- 步骤2：学习节奏推断——根据阶段实际时长与预期时长比值判断节奏
- 步骤3：信心指数计算——综合正确率和情绪均分
- 步骤4：困惑标记生成——提取答错多次或提问频繁的知识点

## 3. 知识/规则定义
- 规则1：掌握度→盲区状态映射——掌握概率≥0.8→标记为"已掌握"，移出knowledge_gaps；0.4≤掌握概率<0.8→保持"学习中"；掌握概率<0.4→标记为"未掌握"，保留或新增至knowledge_gaps
- 规则2：学习节奏推断——阶段实际时长/预期时长<0.7→"过快"；0.7~1.3→"适中"；>1.3→"过慢"
- 规则3：信心指数计算——信心指数 = 正确率 × 0.6 + 情绪均分 × 0.4，输出0~1数值
- 规则4：困惑标记生成——提取本阶段中答错≥2次或提问≥3次的知识点标签，写入confusion_tags

## 4. 输入输出规范
- 输入：修正后掌握概率（各知识点）、策略标签、阶段实际时长、预期时长、正确率、情绪均分、答题记录、提问记录
- 输出：结构化画像更新字段（knowledge_gaps、dynamic_state、pace_adjustment、confidence_index、confusion_tags、next_strategy）

## 5. 异常处理
- 数据不足无法推断节奏 → 保持原有节奏数据，标记为"待确认"
- 掌握度数据矛盾 → 记录日志，以最新计算结果为准
- 多个知识点掌握度相近 → 保留全部，不合并
