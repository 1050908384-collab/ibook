# SKILL名称：quality_metrics

## 1. 能力描述
- 功能：基于多维度质量指标评估学习内容的整体质量
- 适用场景：Agent5进行质量评审
- 前置依赖：学习内容、用户画像

## 2. 核心方法论
- 步骤1：从多个维度评估内容质量
- 步骤2：计算各维度评分
- 步骤3：综合评估整体质量
- 步骤4：生成质量报告

## 3. 知识/规则定义
- 规则1：难度匹配度（0-10分）：内容难度与用户水平的匹配程度
- 规则2：认知负荷（0-10分）：内容复杂度是否在合理范围内
- 规则3：风格适配（0-10分）：内容风格与用户偏好的匹配程度
- 规则4：结构清晰度（0-10分）：内容组织结构是否清晰
- 规则5：实用性（0-10分）：内容是否能解决实际问题

## 4. 输入输出规范
- 输入：学习内容、用户画像
- 输出：质量评估报告，包含各维度评分、总分、改进建议

## 5. 异常处理
- 总分低于60分 → 标记为"质量不达标"，需要重新生成
- 单个维度低于4分 → 标记为"需要改进"

## 6. 附录
- 附录A：质量评估量表
- 附录B：评分标准说明
