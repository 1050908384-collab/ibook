# SKILL名称：quality_metrics

## 1. 能力描述
- 功能：定义综合评分标准与权重，明确"怎么打分和算总分"，评估学习内容的整体质量
- 适用场景：Agent⑤进行质量评审，计算综合评分时
- 前置依赖：各维度评估数据（难度匹配度、认知负荷、环境可行性、风格适配度、情绪友好度、教学逻辑严谨度）

## 2. 核心方法论
- 步骤1：收集六维评估数据——难度匹配度、认知负荷合理度、环境可行性、风格适配度、情绪友好度、教学逻辑严谨度
- 步骤2：按权重计算单项分（每项0~100分）
- 步骤3：检查单项红线——认知负荷>85或环境可行性=0时直接不通过
- 步骤4：计算总分并判定——≥70分通过，否则触发修改

## 3. 知识/规则定义
- 规则1：六维评分体系——难度匹配度（权重20%）、认知负荷合理度（权重25%）、环境可行性（权重10%）、风格适配度（权重10%）、情绪友好度（权重15%）、教学逻辑严谨度（权重20%），每项0~100分
- 规则2：总分及格线——综合得分≥70分判定为"通过"，<70分触发修改建议
- 规则3：单项红线——认知负荷>85或环境可行性=0时，直接不通过，无需计算总分
- 规则4：情绪友好度评估——内容是否照顾用户当前情绪状态，根据emotion_pedagogy.skill.md中的策略判定

## 4. 输入输出规范
- 输入：六维评估数据（各维度得分0~100）、用户情绪状态
- 输出：质量评估报告，包含各维度得分、权重、加权分、总分、最终判定（通过/不通过）、修改建议

## 5. 异常处理
- 某项评估数据缺失 → 该项按60分计算，标记为"数据缺失"
- 总分接近及格线（65~69分）→ 判定为"边缘通过"，建议优化提升
- 多项维度得分低于50分 → 标记为"严重质量问题"，需要大幅修改
