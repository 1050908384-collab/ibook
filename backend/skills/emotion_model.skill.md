# SKILL名称：emotion_model

## 1. 能力描述
- 功能：定义情绪感知规则库，明确"如何从交互中识别情绪并量化"，从用户交互数据中提取情绪状态
- 适用场景：Agent⑥分析用户情绪时，为emotion_analyzer_tool提供情绪识别规则
- 前置依赖：用户文本问答/评论、交互行为日志（求助点击次数等）

## 2. 核心方法论
- 步骤1：情绪标签分类——基于文本关键词和行为信号综合判定情绪标签
- 步骤2：情绪得分计算——根据情绪标签映射到-1~+1的数值
- 步骤3：情绪与学习效果关联——根据情绪状态调整学习效率预估
- 步骤4：为mastery_tracker_tool提供情绪权重We的设定依据

## 3. 知识/规则定义
- 规则1：情绪标签分类规则——基于文本关键词（"好难"→挫败、"原来如此"→开心、"还是不懂"→疑惑）及行为信号（求助点击≥3次→挫败）综合判定，优先以文本分析为主，行为信号为辅
- 规则2：情绪得分计算——积极→0.5~1.0，疑惑→-0.2~0.2，挫败/焦虑→-1.0~-0.3，中性→0.0~0.2
- 规则3：情绪与学习效果关系——情绪积极时学习效率预估提升10%，消极时下降10%，作为mastery_tracker_tool中We的设定依据

## 4. 输入输出规范
- 输入：用户文本问答/评论、交互行为日志（求助点击次数、停留时长、退出次数）
- 输出：情绪标签（挫败/焦虑/开心/疑惑/积极/中性）、情绪得分（-1~+1）、学习效率修正系数

## 5. 异常处理
- 交互数据不足（无文本、无行为日志）→ 标记为"中性"，情绪得分0.0
- 多种情绪信号混合 → 按强度最高的信号判定，记录次要情绪作为参考
- 文本分析歧义 → 结合行为信号辅助判定
