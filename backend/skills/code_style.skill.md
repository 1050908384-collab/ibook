# SKILL名称：code_style

## 1. 能力描述
- 功能：为Agent3生成教程中的Python代码片段提供风格与规范约束，作为内容生成prompt的提示规范
- 适用场景：Agent3（HybridContentAgent）生成含代码示例的Markdown教程时，作为content_skill_context注入prompt
- 前置依赖：无独立工具；仅作为提示文本被LLM读取

## 2. 核心方法论
- 步骤1：教程中Python代码遵循PEP8基本风格
- 步骤2：关键函数/类附中文docstring与关键步骤注释
- 步骤3：文件读写、模型加载、推理等步骤配异常处理示例
- 步骤4：禁止硬编码密钥/GPU编号/账号，统一用配置读取

## 3. 知识/规则定义
- 规则1：单行字符上限88，导入分标准库/第三方/本地三层
- 规则2：顶层函数与类必须有docstring，标注入参、返回值、功能
- 规则3：循环、模型加载、推理等关键步骤单行注释
- 规则4：文件IO/模型推理/网络请求必须try-except
- 规则5：禁止硬编码敏感信息

## 4. 输入输出规范
- 输入：无独立输入；作为提示文本注入教程生成prompt
- 输出：约束LLM生成教程内代码片段风格（不产出独立校验报告）

## 5. 异常处理
- 本技能为被动提示，不执行实际校验；代码规范违规由Agent4技术审核兜底

## 6. 附录
- 附录A：Python PEP8核心要点速查
- 附录B：教程内代码示例风格模板
