# SKILL名称：code_style

## 1. 能力描述
- 功能：确保生成的代码示例符合行业规范和最佳实践
- 适用场景：Agent3生成代码示例、Agent4审核代码
- 前置依赖：代码内容

## 2. 核心方法论
- 步骤1：检查代码语法正确性
- 步骤2：验证代码风格一致性
- 步骤3：确保注释充分且清晰
- 步骤4：检查异常处理完整性

## 3. 知识/规则定义
- 规则1：Python代码遵循PEP 8规范
- 规则2：函数和类必须有文档字符串
- 规则3：关键步骤必须有注释说明
- 规则4：必须处理可能的异常情况
- 规则5：代码必须包含必要的导入语句

## 4. 输入输出规范
- 输入：代码字符串
- 输出：代码质量评估结果，包含错误列表和改进建议

## 5. 异常处理
- 代码语法错误 → 标记为严重问题，需要修复
- 注释不足 → 标记为中等问题，建议补充

## 6. 附录
- 附录A：PEP 8规范要点
- 附录B：代码审查检查清单
