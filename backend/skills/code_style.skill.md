# SKILL名称：code_style

## 1. 能力描述
- 功能：定义Python/C++代码规范与安全审核规则库，批量检测代码语法、命名、注释、异常、敏感信息问题，输出可量化质量评估结果与修复方案，为代码生成、代码审核提供校验标准
- 适用场景：Agent3生成实训代码时自检、Agent4 code_reviewer_tool执行代码审查
- 前置依赖：待校验完整代码字符串、编程语言类型、交互上下文（可选）

## 2. 核心方法论
- 步骤1：解析代码文本，校验基础语法正确性，捕获语法报错
- 步骤2：逐行验证代码命名、缩进、导入分组、行长度等PEP8风格规范
- 步骤3：扫描类、函数，检查文档字符串、关键步骤注释完整性
- 步骤4：全局检索异常捕获逻辑，判断边界场景覆盖完整性
- 步骤5：识别硬编码密钥、固定GPU卡号等高危敏感代码，汇总所有违规项输出报告

## 3. 知识/规则定义
- 规则1：Python代码严格遵循PEP8规范，单行字符上限88，导入分标准库/第三方/本地三层分组
- 规则2：所有类、顶层函数必须添加中文docstring，标注入参、返回值、功能说明
- 规则3：循环、模型加载、推理等关键业务步骤必须单行注释说明逻辑
- 规则4：文件读写、模型推理、网络请求必须配套try-except异常捕获
- 规则5：禁止硬编码API密钥、GPU编号、数据库账号等敏感信息，统一使用配置读取

## 4. 输入输出规范
- 输入：完整代码字符串、编程语言标识（Python/C++）
- 输出：代码质量评估JSON，包含严重/中等/轻微错误列表、对应代码行号、标准化改进建议、修复后完整代码

## 5. 异常处理
- 代码语法解析失败 → 标记为严重级问题，仅输出语法报错，不阻断整体内容审核流程
- 输入为空代码字符串 → 返回无代码待校验提示，无违规列表
- 语言类型不支持 → 跳过风格校验，仅做基础语法检测
