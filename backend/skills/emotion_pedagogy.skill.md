# SKILL名称：emotion_pedagogy

## 1. 能力描述
- 功能：定义情绪应对策略库，明确"根据情绪状态做什么"，为教学内容优化提供情绪适配建议
- 适用场景：Agent⑤评估内容的情绪友好度，生成情绪优化意见时
- 前置依赖：用户情绪状态（情绪标签、情绪得分）、学习内容

## 2. 核心方法论
- 步骤1：识别情绪状态——根据情绪得分和标签判断用户当前情绪
- 步骤2：匹配应对策略——根据情绪→行动映射表选择合适的教学动作
- 步骤3：生成优化建议——将策略转化为具体的内容修改建议
- 步骤4：写入评审报告——将建议写入"情绪优化意见"字段

## 3. 知识/规则定义
- 规则1：情绪→行动映射——挫败/焦虑（得分 < -0.3）→ 建议在内容开头插入鼓励语、增加过渡性练习、降低本阶段目标预期；积极/开心（得分 > 0.5）→ 建议推送拓展阅读或进阶挑战，维持心流；疑惑（得分在 -0.3~0.3 且提问频次高）→ 建议在本阶段增加类比案例或FAQ附录
- 规则2：输出规范——本SKILL仅产出"教学动作建议"，不直接修改内容，而是将建议写入评审报告的"情绪优化意见"字段
- 规则3：情绪持续跟踪——若用户连续两阶段情绪消极，建议调整整体学习路径或安排复习阶段

## 4. 输入输出规范
- 输入：用户情绪状态（情绪标签、情绪得分、提问频次）、学习内容摘要
- 输出：情绪优化意见，包含当前情绪分析、建议教学动作、具体内容修改建议

## 5. 异常处理
- 情绪数据缺失 → 跳过情绪评估，标记为"情绪数据不足"
- 情绪状态模糊（多种情绪混合）→ 按主导情绪处理，记录其他情绪作为参考

## 6. 附录
- 附录A：参考标准——情绪心理学、情感化设计理论、心流理论
- 附录B：示例——用户当前情绪为"挫败"（得分-0.5），建议在内容开头增加鼓励语"这个概念确实有难度，很多同学刚开始都会觉得困惑，我们一步步来拆解"，并增加2个过渡性练习
