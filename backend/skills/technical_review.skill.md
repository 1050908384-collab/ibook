# SKILL名称：technical_review

## 1. 能力描述
- 功能：检查学习内容的技术正确性，检测幻觉和错误
- 适用场景：Agent4审核Agent3生成的学习包和回答
- 前置依赖：待审核的内容、知识库

## 2. 核心方法论
- 步骤1：提取内容中的技术陈述
- 步骤2：对照知识库验证技术准确性
- 步骤3：检查代码语法和逻辑正确性
- 步骤4：生成技术错误报告

## 3. 知识/规则定义
- 规则1：技术陈述必须有知识库依据
- 规则2：代码必须可编译/可运行
- 规则3：参数配置必须符合行业规范
- 规则4：算法描述必须准确无误

## 4. 输入输出规范
- 输入：学习包JSON或回答字符串
- 输出：技术错误列表，包含错误类型、位置、描述、建议修复方案

## 5. 异常处理
- 无法验证的技术陈述 → 标记为"待确认"，建议补充知识库
- 多个严重错误 → 标记为"审核不通过"，需要重新生成

## 6. 附录
- 附录A：技术错误类型分类
- 附录B：审核检查清单
