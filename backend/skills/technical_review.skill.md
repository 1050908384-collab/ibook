# SKILL名称：technical_review

## 1. 能力描述
- 功能：为技术审核提供审核标准与错误模式库，定义"什么是错"
- 适用场景：Agent④审核学习包或回答的技术正确性时
- 前置依赖：待审核的内容、知识库、标准答案库

## 2. 核心方法论
- 步骤1：设定幻觉判定阈值，区分潜在幻觉、存疑和可信内容
- 步骤2：建立常见错误模式库，识别参数类型错误、API调用过时等问题
- 步骤3：定义报错分级标准，区分Critical、Major、Minor三级错误
- 步骤4：结合工具输出，生成结构化错误报告

## 3. 知识/规则定义
- 规则1：幻觉判定阈值——知识库相似度 < 0.65 标记为"潜在幻觉"，0.65~0.80 标记为"存疑需人工复核"，≥0.80 标记为"有依据"
- 规则2：常见错误模式库——参数类型错误、API调用过时（如 `torch.cuda` 旧写法）、路径硬编码、配置文件缺失必填项
- 规则3：报错分级标准——Critical（致命）：语法错误、依赖冲突、安全规范违规 → 直接不通过；Major（主要）：幻觉、标准答案偏离 → 需修改；Minor（次要）：风格建议、冗余描述 → 建议修改

## 4. 输入输出规范
- 输入：审核工具输出（AST解析结果、知识库相似度、标准答案比对结果、规则检查结果）
- 输出：结构化错误报告，包含错误类型、级别、位置、描述、证据来源、建议修复方案

## 5. 异常处理
- 知识库相似度无法计算 → 标记为"存疑"，建议人工复核
- 错误模式未覆盖的新型错误 → 归入"其他"类别，记录日志供后续更新规则库
- 多工具结果冲突 → 遵循 hallucination_detection.skill.md 的裁决优先级

## 6. 附录
- 附录A：参考标准——技术文档写作规范、代码质量检查清单
- 附录B：示例——某技术陈述知识库相似度为0.52，标记为"潜在幻觉"，建议验证后修改
