# SKILL名称：iteration_strategy

## 1. 能力描述
- 功能：根据阶段测试结果选择下一阶段的学习策略
- 适用场景：Agent6决策下一阶段策略
- 前置依赖：阶段正确率、用户画像

## 2. 核心方法论
- 步骤1：分析阶段正确率
- 步骤2：综合考虑用户画像中的信心指数和学习节奏
- 步骤3：选择合适的学习策略
- 步骤4：生成策略说明

## 3. 知识/规则定义
- 规则1：正确率≥80% → 正常推进，进入下一知识板块
- 规则2：60%≤正确率<80% → 巩固复习，增加练习量
- 规则3：正确率<60% → 降级学习，降低难度或返回先修内容

## 4. 输入输出规范
- 输入：阶段正确率（0-1）、用户画像
- 输出：策略类型（normal/consolidate/retreat）、策略说明

## 5. 异常处理
- 连续两次正确率<60% → 触发人工干预提醒
- 正确率波动过大 → 建议保持当前策略观察

## 6. 附录
- 附录A：策略选择决策树
- 附录B：策略实施建议
