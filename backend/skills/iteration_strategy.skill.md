# SKILL名称：iteration_strategy

## 1. 能力描述
- 功能：定义策略选择规则库，明确"什么条件下选什么策略"，根据阶段测试结果选择下一阶段学习策略
- 适用场景：Agent⑥决策下一阶段学习策略时
- 前置依赖：阶段正确率、盲区覆盖率、用户画像、迭代历史

## 2. 核心方法论
- 步骤1：计算阶段正确率和盲区覆盖率
- 步骤2：对照四档策略表匹配策略标签
- 步骤3：检查特殊情况——降维连续2轮无效时自动切换回溯
- 步骤4：记录策略方向切换日志，供Orchestrator防死循环判断

## 3. 知识/规则定义
- 规则1：四档策略表——正确率 ≥ 85% 且 覆盖率 ≥ 90% → 结业（终止迭代）；正确率 ≥ 80% → 进阶（推送更难/更综合的任务）；60% ≤ 正确率 < 80% → 巩固（同难度补充练习）；正确率 < 60% → 降维（降低难度重讲解）；降维连续2轮无效（正确率提升 < 5%）→ 自动切换回溯（推荐前置知识模块）
- 规则2：方向切换触发条件——策略标签变化时必须记录日志，包含切换原因、前后策略、当前数据，供Orchestrator进行防死循环判断
- 规则3：结业判定——同时满足正确率≥85%和覆盖率≥90%时方可结业，任一条件不满足则继续迭代

## 4. 输入输出规范
- 输入：阶段正确率（0~1）、盲区覆盖率（0~1）、迭代历史（轮次、方向、效果）、用户画像
- 输出：策略标签（进阶/巩固/降维/回溯/结业）、决策理由、迭代日志

## 5. 异常处理
- 数据不足（如仅完成1题）→ 保持当前策略，标记为"数据不足"
- 连续3次策略切换 → 触发人工干预提醒
- 正确率与覆盖率矛盾（如正确率高但覆盖率低）→ 优先按正确率判定，同时建议补充未覆盖知识点
