# SKILL名称：learner_profiling

## 1. 能力描述
- 功能：从用户自然语言输入中提取技能标签、知识盲区，计算画像置信度，生成结构化用户画像
- 适用场景：用户首次输入、Agent6更新数据后重新生成画像
- 前置依赖：用户输入文本、可选的历史交互数据

## 2. 核心方法论
- 步骤1：识别用户输入中的技术术语和技能描述
- 步骤2：对照知识图谱标签体系，提取匹配的技能标签
- 步骤3：根据用户描述推断知识盲区和掌握程度
- 步骤4：结合输入信息量计算画像置信度

## 3. 知识/规则定义
- 规则1：技能标签必须来自预定义的标签体系（如"PyTorch基础""Transformer架构""LoRA微调"）
- 规则2：知识盲区状态分为"未开始""部分掌握""已掌握"三个等级
- 规则3：置信度计算考虑输入长度、明确程度、完整性等因素
- 规则4：当置信度低于阈值（0.7）时，需要生成追问问题

## 4. 输入输出规范
- 输入：用户自然语言文本（学习背景、目标、每日时长、学习偏好）
- 输出：结构化画像JSON，包含skill_tags、knowledge_gaps、goal、daily_hours、learning_style、confidence等字段

## 5. 异常处理
- 用户输入过短或信息不足 → 降低置信度，生成追问问题
- 无法识别的技术术语 → 标记为待确认，后续通过追问澄清
