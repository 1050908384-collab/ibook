# SKILL名称：learner_profiling

## 1. 能力描述
- 功能：从用户自然语言输入提取标准化技能标签、划分知识盲区掌握等级，自动计算画像置信度，输出结构化学习者画像；置信不足时生成追问话术补齐信息
- 适用场景：用户首次对话录入学习信息、Agent6同步更新学习行为后重新生成画像
- 前置依赖：用户原始对话文本、可选历史交互记录、项目全局知识图谱标签库

## 2. 核心方法论
- 步骤1：识别用户输入内大模型相关技术术语、学习目标、可投入时长、学习基础，学习风格
- 步骤2：对照知识图谱预设标签体系，精准匹配skill_tags，过滤无效描述
- 步骤3：根据用户描述划分知识盲区三档状态：未开始/部分掌握/已掌握
- 步骤4：综合输入长度、信息完整度、表述明确度计算画像置信度
- 步骤5：置信度低于阈值0.7时，生成针对性追问模板补充缺失学情

## 3. 知识/规则定义
- 规则1：技能标签必须取自项目预定义体系，例如`PyTorch基础`、`Transformer架构`、`LoRA微调`，禁止自定义陌生标签
- 规则2：知识盲区仅分为「未开始」「部分掌握」「已掌握」三个固定等级，用于阶段规划排序
- 规则3：置信度计算公式包含4项权重：学习目标清晰度、每日时长明确度、技术背景完整度、学习偏好描述
- 规则4：置信度＜0.7必须输出追问列表，不可直接生成不完整画像

## 4. 输入输出规范
- 输入：用户自然语言文本（学习背景、训练目标、每日可投入时长、学习偏好）；可选历史交互JSON
- 输出：结构化画像JSON，字段包含 skill_tags、knowledge_gaps、goal、daily_hours、learning_style、confidence、follow_up_questions（置信不足时存在）

## 5. 异常处理
- 用户输入过短、无有效学习信息 → 大幅降低置信度，强制生成追问话术
- 文本内无法识别的专业术语 → 标记待确认标签，后续通过追问澄清，不丢弃
- 标签库读取失败 → 置信度强制置0.5，仅保留原始文本描述，阻断自动阶段规划
