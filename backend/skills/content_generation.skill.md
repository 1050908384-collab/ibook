# SKILL名称：content_generation

## 1. 能力描述
- 功能：根据知识板块信息生成完整的学习资料包（教程、代码示例、测试题）
- 适用场景：Agent3生成学习包、回答用户问题
- 前置依赖：知识板块ID、相关文档向量检索结果

## 2. 核心方法论
- 步骤1：从向量库检索相关知识文档
- 步骤2：调用LLM生成结构化教程内容（Markdown格式）
- 步骤3：生成配套代码示例
- 步骤4：从题库抽取测试题
- 步骤5：组装成完整学习包

## 3. 知识/规则定义
- 规则1：教程必须遵循清晰的结构（概述、核心概念、步骤演示、总结）
- 规则2：代码示例必须可运行，包含注释和说明
- 规则3：测试题覆盖知识板块的核心知识点
- 规则4：内容难度匹配用户画像中的学习风格和当前水平

## 4. 输入输出规范
- 输入：知识板块ID、用户画像（用于难度适配）
- 输出：学习包JSON，包含tutorial（Markdown）、code_examples（列表）、questions（列表）

## 5. 异常处理
- 向量检索结果为空 → 使用通用知识库生成内容，标记为低置信度
- LLM生成失败 → 返回错误，触发重试机制

## 6. 附录
- 附录A：教程模板结构
- 附录B：代码示例格式要求
