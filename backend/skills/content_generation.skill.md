# SKILL名称：content_generation

## 1. 能力描述
- 功能：接收单阶段板块ID与用户画像，检索向量知识库生成整套学习资料包（Markdown教程、规范实训代码、配套测试题）；同时支持接收用户提问生成实时答疑内容
- 适用场景：Agent3初始化阶段学习包、用户学习过程中实时提问答疑
- 前置依赖：知识板块ID、用户画像（难度适配）、本地向量知识库、题库SQLite、code_style规范校验工具

## 2. 核心方法论
- 步骤1：根据block_id检索向量库匹配相关知识文档片段
- 步骤2：结合用户画像水平，调用LLM生成适配难度的结构化Markdown教程
- 步骤3：生成配套Python实训代码，自动调用code_style技能校验代码规范
- 步骤4：从题库抽取对应知识点客观测试题，覆盖阶段核心内容
- 步骤5：统一模板组装完整学习包，输出标准化JSON结构

## 3. 知识/规则定义
- 规则1：教程固定三段式结构：概述→核心概念→代码演示→总结，不可缺失模块
- 规则2：生成代码必须通过code_style规范校验，无PEP8、注释、异常处理违规项
- 规则3：单阶段测试题不少于3道，覆盖本板块全部核心知识点
- 规则4：内容难度严格匹配画像学习水平，新手增加基础扫盲，高阶用户补充底层原理拓展

## 4. 输入输出规范
- 输入：知识板块ID、完整用户画像JSON；若为答疑模式则附加用户提问文本
- 输出：学习包JSON，包含 tutorial(Markdown)、code_examples(代码列表)、questions(测试题列表)；答疑模式输出纯文本回答

## 5. 异常处理
- 向量检索无匹配知识库文档 → 使用通用基础模板生成内容，标记低置信度标识
- LLM生成超时/失败 → 触发重试机制，重试失败返回精简入门内容，降低内容复杂度
- 代码规范校验大量违规 → 自动修正代码，附带违规清单存入学习包备注
