# SKILL名称：learner_model

## 1. 能力描述
- 功能：根据用户画像评估学习内容是否匹配不同学习者的认知特征
- 适用场景：Agent5评估内容的适应性
- 前置依赖：用户画像、学习内容

## 2. 核心方法论
- 步骤1：分析用户的学习风格（理论型/实操型/混合型）
- 步骤2：评估内容是否匹配用户的认知特征
- 步骤3：检查内容难度是否适合用户当前水平
- 步骤4：生成适应性评估结果

## 3. 知识/规则定义
- 规则1：理论型学习者需要更多概念解释和原理说明
- 规则2：实操型学习者需要更多代码示例和动手练习
- 规则3：难度应略高于用户当前水平（i+1原则）
- 规则4：内容量不应超出用户的认知负荷

## 4. 输入输出规范
- 输入：用户画像、学习内容
- 输出：适应性评估结果，包含匹配度评分和改进建议

## 5. 异常处理
- 内容与学习风格严重不匹配 → 标记为严重问题，需要重新生成
- 难度过高或过低 → 标记为中等问题，建议调整

## 6. 附录
- 附录A：学习风格分类及特征
- 附录B：认知负荷评估方法
