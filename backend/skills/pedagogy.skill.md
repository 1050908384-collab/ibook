# SKILL名称：pedagogy

## 1. 能力描述
- 功能：定义教学法原理库，明确"好的教学长什么样"，评估学习内容的教学设计质量
- 适用场景：Agent⑤评估学习内容的教学逻辑和设计时
- 前置依赖：学习内容、用户画像

## 2. 核心方法论
- 步骤1：检查脚手架原则——新内容是否建立在已有知识之上，每步只引入1~2个新概念
- 步骤2：验证渐进式讲解规范——顺序是否为"已知回顾 → 核心概念拆解 → 实操演示 → 常见坑点 → 自测"
- 步骤3：评估认知负荷——单次学习新概念不超过5±2个，超载则需拆分
- 步骤4：检查建构主义要求——是否提供情境化案例，让学习者在真实问题中建构知识

## 3. 知识/规则定义
- 规则1：脚手架原则——新内容必须建立在学习者已有知识基础之上，每一步只引入1~2个新概念，避免认知过载
- 规则2：渐进式讲解规范——内容组织顺序必须遵循"已知回顾 → 核心概念拆解 → 实操演示 → 常见坑点 → 自测"的逻辑
- 规则3：认知负荷理论——工作记忆容量有限，单次学习新概念数量不超过5±2个，超过则需拆分阶段或提供辅助材料
- 规则4：建构主义要求——内容需提供情境化案例，让学习者在解决真实问题的过程中建构知识，而非单纯被动接受

## 4. 输入输出规范
- 输入：学习内容（文本、代码、示例）、用户画像（学习基础、已掌握技能）
- 输出：教学质量评估结果，包含各教学法原则的符合度评分、优点、改进建议

## 5. 异常处理
- 教学结构混乱，违反多项原则 → 标记为严重问题，需要重新组织内容
- 认知负荷超载（新概念数量>7个）→ 强制拆分内容，降低负荷
- 缺少实践环节 → 标记为中等问题，建议补充案例和练习
