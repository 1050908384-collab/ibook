# SKILL名称：pedagogy

## 1. 能力描述
- 功能：应用教学法理论评估学习内容的教学质量
- 适用场景：Agent5评估学习内容的教学设计
- 前置依赖：学习内容、用户画像

## 2. 核心方法论
- 步骤1：分析内容的教学结构是否合理
- 步骤2：评估知识点的呈现顺序是否符合认知规律
- 步骤3：检查是否包含足够的练习和反馈环节
- 步骤4：评估是否采用了有效的教学策略

## 3. 知识/规则定义
- 规则1：内容应遵循"从易到难、从基础到高级"的顺序
- 规则2：复杂概念需要分步讲解
- 规则3：应该包含示例、练习和总结
- 规则4：使用多种教学方法（讲解、演示、实践）

## 4. 输入输出规范
- 输入：学习内容、用户画像（学习风格、水平）
- 输出：教学质量评估结果，包含优点和改进建议

## 5. 异常处理
- 教学结构混乱 → 标记为严重问题，需要重新组织内容
- 缺乏练习环节 → 标记为中等问题，建议补充

## 6. 附录
- 附录A：教学法理论参考
- 附录B：教学设计评估标准
