# SKILL名称：industry_standards

## 1. 能力描述
- 功能：定义领域合规规则库，明确"行业红线"，检查学习内容是否符合大模型微调与部署的行业规范
- 适用场景：Agent④审核内容中的规范合规性时
- 前置依赖：待审核的内容、行业规范规则库

## 2. 核心方法论
- 步骤1：检查安全规范——禁止硬编码API密钥、禁止暴露内部端口、必须包含权限校验
- 步骤2：验证部署规范——模型许可证合规、显存最低要求标注
- 步骤3：检查数据隐私——涉及用户数据的操作必须脱敏或加匿名化提示
- 步骤4：生成规范违规报告，列出违规项及违反条款编号

## 3. 知识/规则定义
- 规则1：安全规范——禁止硬编码API密钥或敏感配置信息；禁止暴露内部服务端口到公网；涉及权限控制的操作必须包含权限校验逻辑
- 规则2：部署规范——模型许可证合规检查（如不可商用模型不可用于生产环境）；部署文档必须标注显存最低要求；资源配置建议必须合理
- 规则3：数据隐私——涉及用户数据的操作必须包含脱敏或匿名化提示；禁止在示例代码中使用真实用户数据；数据传输必须加密

## 4. 输入输出规范
- 输入：待审核的学习内容（代码、配置、文档）
- 输出：规范违规列表，包含违规类型、位置、违反条款编号、描述、建议修复方案

## 5. 异常处理
- 发现严重安全隐患（如硬编码密钥）→ 标记为"Critical"，直接不通过，阻止内容发布
- 轻微违规（如缺少许可证说明）→ 标记为"Minor"，建议补充完善
- 规则未覆盖的新型合规问题 → 归入"待评估"类别，记录日志供规则库更新

## 6. 附录
- 附录A：参考标准——OWASP安全规范、模型许可证合规指南、GDPR数据隐私要求
- 附录B：示例——某代码包含硬编码API密钥，标记为安全规范违规（条款1），建议使用环境变量或密钥管理服务
