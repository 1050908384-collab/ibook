# SKILL名称：industry_standards

## 1. 能力描述
- 功能：检查学习内容是否符合大模型微调与部署的行业规范和最佳实践
- 适用场景：Agent4审核内容中的规范合规性
- 前置依赖：待审核的内容

## 2. 核心方法论
- 步骤1：检查内容是否符合安全规范
- 步骤2：验证部署配置是否合理
- 步骤3：检查数据处理是否合规
- 步骤4：生成规范违规报告

## 3. 知识/规则定义
- 规则1：模型训练必须考虑数据隐私保护
- 规则2：部署配置必须符合安全最佳实践
- 规则3：超参数设置必须在合理范围内
- 规则4：文档必须包含必要的安全提示

## 4. 输入输出规范
- 输入：学习内容
- 输出：规范违规列表，包含违规类型、位置、描述、建议

## 5. 异常处理
- 发现严重安全隐患 → 标记为"必须修复"，阻止内容发布
- 轻微违规 → 标记为"建议改进"

## 6. 附录
- 附录A：安全规范清单
- 附录B：部署最佳实践指南
