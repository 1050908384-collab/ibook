# SKILL名称：knowledge_graph_mapping

## 1. 能力描述
- 功能：接收技能标签/知识板块ID，查询图谱节点与前置依赖关系，递归推导完整学习先后顺序，输出结构化依赖列表，供画像、阶段规划模块调用
- 适用场景：Agent1生成学习者画像时扩展知识盲区、Agent2 stage_planning规划单阶段学习路径，全局共享工具技能
- 前置依赖：本地SQLite知识图谱数据库、标准化技能标签映射表

## 2. 核心方法论
- 步骤1：接收技能名称/板块ID，清洗文本后匹配图谱唯一节点
- 步骤2：递归查询当前节点所有入边，提取全部先修依赖板块
- 步骤3：校验依赖传递关系，过滤循环依赖、重复板块
- 步骤4：依赖链超过3层时生成分层提示，输出完整结构化依赖数组

## 3. 知识/规则定义
- 规则1：所有先修依赖必须是图谱中已存在标准知识板块，不生成临时自定义节点
- 规则2：依赖具备传递性：A依赖B、B依赖C，则A必须前置学习C
- 规则3：依赖链层级超过3层，需标记提示用户拆分多阶段学习，避免单阶段负荷过重
- 规则4：输出依赖列表自动去重，同一板块不重复展示

## 4. 输入输出规范
- 输入：技能名称字符串 / 知识板块唯一ID
- 输出：先修依赖列表JSON，单条包含 block_id、block_name、difficulty、estimated_hours

## 5. 异常处理
- 输入技能名称在图谱无匹配节点 → 返回空列表，日志记录缺失标签，提示补充图谱数据
- 检测到循环依赖（A依赖B、B依赖A）→ 截断循环链路，返回部分有效依赖并标记警告日志
- 数据库文件读取失败 → 返回空数组，上层StagePlanning自动切换通用入门模板
