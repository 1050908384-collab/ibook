# SKILL名称：knowledge_graph_mapping

## 1. 能力描述
- 功能：查询知识图谱，获取知识点之间的先修依赖关系
- 适用场景：Agent1扩展知识盲区、Agent2规划学习路径
- 前置依赖：知识图谱已构建完成

## 2. 核心方法论
- 步骤1：根据技能名称匹配图谱中的节点
- 步骤2：查询节点的入边（先修依赖）
- 步骤3：验证依赖关系的完整性
- 步骤4：返回结构化的依赖列表

## 3. 知识/规则定义
- 规则1：先修依赖必须是已存在的知识板块
- 规则2：依赖关系具有传递性（A依赖B，B依赖C，则A依赖C）
- 规则3：如果依赖链过长（超过3层），需要提示用户分步学习

## 4. 输入输出规范
- 输入：技能名称或知识板块ID
- 输出：先修依赖列表，包含板块ID、名称、难度等级

## 5. 异常处理
- 技能名称在图谱中不存在 → 返回空列表，提示需要补充图谱数据
- 循环依赖检测 → 记录日志，返回部分依赖
