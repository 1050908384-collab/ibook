# SKILL名称：knowledge_graph_mapping

## 1. 能力描述
- 功能：按技能标签/板块ID查询知识图谱节点与先修依赖，递归推导学习先后顺序
- 适用场景：旧框架Agent1/2依赖查询；新框架（v2.0+）已移除知识图谱子系统，本技能当前未被加载，规则保留备查
- 前置依赖：本地SQLite知识图谱数据库、标准化技能标签映射表（新框架均未启用）

## 2. 核心方法论
- 步骤1：接收技能名称/板块ID，匹配图谱唯一节点
- 步骤2：递归查询入边，提取全部先修依赖板块
- 步骤3：校验依赖传递性，过滤循环依赖、重复板块
- 步骤4：依赖链超3层生成分层提示，输出结构化依赖数组

## 3. 知识/规则定义
- 规则1：先修依赖必须是图谱中已存在标准板块，不生成临时节点
- 规则2：依赖具备传递性
- 规则3：依赖链超3层标记拆分多阶段提示
- 规则4：输出依赖列表自动去重

## 4. 输入输出规范
- 输入：技能名称字符串 / 知识板块唯一ID
- 输出：先修依赖列表JSON，单条含 block_id、block_name、difficulty、estimated_hours

## 5. 异常处理
- 无匹配节点 → 返回空列表，记录缺失标签
- 检测循环依赖 → 截断循环，返回部分有效依赖并警告
- 数据库读取失败 → 返回空数组
