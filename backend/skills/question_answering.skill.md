# SKILL名称：question_answering

## 1. 能力描述
- 功能：解析用户学习过程中的提问，检索向量知识库匹配对应知识点，结合用户画像水平生成适配深度的精准回答，规避大模型幻觉
- 适用场景：Agent3接收用户实时对话提问，阶段学习内答疑交互
- 前置依赖：用户提问字符串、当前阶段向量检索文档、学习者画像、同会话历史问答记录

## 2. 核心方法论
- 步骤1：分词分析用户问题，提取核心技术关键词，区分通用提问/当前阶段知识点提问
- 步骤2：向量检索知识库，匹配和当前学习板块相关的文档片段
- 步骤3：读取用户画像学习水平，调整回答深度：新手通俗简化、高阶补充底层原理
- 步骤4：基于检索到的真实知识库内容生成回答，附带简易可运行代码示例（技术类问题）

## 3. 知识/规则定义
- 规则1：回答内容必须完全依托检索知识库，禁止LLM凭空编造参数、模型原理、代码逻辑
- 规则2：回答简洁直击核心，复杂原理分多步骤分段解释，避免大段无分段文本
- 规则3：无法检索到匹配知识点时，明确告知用户，并给出学习建议，不编造模糊答案
- 规则4：同Session重复提问，复用历史问答记录，简化重复基础说明

## 4. 输入输出规范
- 输入：用户提问字符串、当前阶段知识库检索文档、学习者画像JSON、会话历史问答列表
- 输出：结构化答疑文本，包含通俗解释、配套代码示例、关联当前阶段知识点提示

## 5. 异常处理
- 知识库无匹配相关知识片段 → 返回标准话术：当前阶段未覆盖该知识点，建议完成本阶段学习后再提问
- 用户问题语义模糊、存在歧义 → 生成追问话术引导用户补充提问细节
- 问题与当前学习板块无关 → 简短作答，同时提示优先聚焦本阶段核心内容
