# SKILL名称：question_answering

## 1. 能力描述
- 功能：基于知识库回答用户学习过程中的问题
- 适用场景：Agent3回答用户实时提问
- 前置依赖：用户问题、知识库向量检索

## 2. 核心方法论
- 步骤1：分析用户问题，提取关键词
- 步骤2：向量检索相关知识文档
- 步骤3：基于检索结果生成回答
- 步骤4：确保回答准确、清晰、有用

## 3. 知识/规则定义
- 规则1：回答必须基于知识库中的内容，避免幻觉
- 规则2：回答应该简洁明了，直击问题核心
- 规则3：复杂问题需要分步骤解释
- 规则4：如果无法回答，应该明确说明并给出建议

## 4. 输入输出规范
- 输入：用户问题字符串
- 输出：回答字符串

## 5. 异常处理
- 无法找到相关知识 → 返回"无法回答"，建议参考其他资源
- 问题歧义 → 追问用户澄清

## 6. 附录
- 附录A：回答模板
- 附录B：常见问题类型及处理策略
