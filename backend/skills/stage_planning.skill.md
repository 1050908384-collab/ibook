# SKILL名称：stage_planning

## 1. 能力描述
- 功能：根据用户画像中的知识盲区和学习目标，生成下一阶段的学习目录信息
- 适用场景：Agent2规划学习阶段、生成完整学习路径
- 前置依赖：用户画像（knowledge_gaps + goal）、知识图谱

## 2. 核心方法论
- 步骤1：筛选状态为"未开始"的知识盲区
- 步骤2：根据知识图谱检查先修依赖是否满足
- 步骤3：选择最优先学习的知识板块
- 步骤4：生成阶段目录信息（标题、预估时长、前置要求）

## 3. 知识/规则定义
- 规则1：优先选择没有未完成先修依赖的盲区
- 规则2：预估时长参考知识板块的estimated_hours字段
- 规则3：如果存在多个可选板块，优先选择与目标关联度高的

## 4. 输入输出规范
- 输入：用户画像JSON（knowledge_gaps + goal）
- 输出：阶段目录信息JSON，包含stage_id、block_id、block_name、estimated_hours、prerequisites等

## 5. 异常处理
- 所有盲区都有未完成的先修依赖 → 提示用户先完成前置学习
- 所有盲区已掌握 → 返回完成状态
