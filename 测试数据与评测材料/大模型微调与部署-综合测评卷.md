### KB-06　注意力机制

**第 20 题** 　**A**
Query 表示"查询"，与各 Key 计算相似度以决定对 Value 的加权。

**第 21 题**
公式：`score = (Q · Kᵀ) / √d_k`。代入：`(1×0 + 0×1) / √2 = 0 / 1.414 = 0`。

**第 22 题**
```python
import math
import torch
import torch.nn.functional as F


def scaled_dot_product_attention(Q, K, V, mask=None):
    """Attention(Q, K, V) = softmax(Q Kᵀ / √d_k) V"""
    d_k = K.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights
```
要点：点积 → 缩放 √d_k → （可选）掩码填 -inf → softmax → 对 V 加权求和。

- **BPE 的问题**：编码通常依赖空格分隔单词；解码时需要额外规则判断何时在子词间添加空格，处理不同语言或不规范文本时易出错。
- **SentencePiece 的解决**：将空格也作为特殊字符（常记为 `▁`）纳入词表，解码时可直接输出空格，无需后处理规则，实现更干净、更通用的可逆解码。

### KB-12　参数高效微调（LoRA 与 QLoRA）

**第 40 题** 　**B**
LoRA 冻结原权重 W，在旁路引入两个低秩矩阵 A、B，用 ΔW = B·A 近似权重更新，前向为 `h = Wx + (alpha/r)·B·A·x`。只训练 A、B，可训练参数量大幅下降。A（全参微调）、C（剪枝）、D（量化非必需）均错。

**第 41 题**
秩大小参数为 `r`；缩放因子为 `lora_alpha`；实际缩放比例为 `alpha / r`（即 `lora_alpha / r`）。

**第 42 题**（任列两项并简述即可）
- **4-bit NF4 量化**：将基座模型权重量化为 4-bit NormalFloat（NF4），大幅降低基座模型显存占用（计算时反量化回高精度）。
- **双重量化（Double Quantization）**：对量化过程产生的量化常数再做一次量化，进一步节省显存。
- **分页优化器（Paged Optimizers）**：借助 NVIDIA 统一内存，在显存峰值（如长序列）时将优化器状态临时分页到 CPU 内存，避免 OOM。
- 效果：QLoRA 使得在单张消费级 GPU（如显存 ≥12GB）上微调较大模型成为可能。

### KB-13　PyTorch 进阶训练技巧

**第 43 题** 　**B**
梯度累积在显存有限时，将多个小 batch 的梯度累加后再统一 `optimizer.step()`，等效于放大 batch size，而不增加单步显存峰值。

**第 44 题**
自动选择算子精度的上下文管理器为 `torch.autocast`（即 `torch.cuda.amp.autocast`）；防止 FP16 梯度下溢的组件为 `GradScaler`（`torch.cuda.amp.GradScaler`，通过对 loss 放大再对梯度还原）。

**第 45 题**
- **原理**：前向传播时不保存中间层的全部激活值，只保存少量"检查点"；反向传播需要激活时，从最近检查点**重新前向计算**得到，从而用计算换显存，显著降低激活值显存占用。
- **主要代价**：需要额外的一次（部分）前向重计算，**训练时间/计算量增加**（通常慢约 20%~30%）。

### KB-14　分布式训练（DeepSpeed）

**第 46 题** 　**C**
ZeRO-1 分片优化器状态；ZeRO-2 再加梯度；ZeRO-3 进一步分片模型参数，即"优化器状态 + 梯度 + 参数"三者都切分，单卡显存约降至 1/N。

**第 47 题** 　**正确**
数据并行中每卡持有完整模型副本，各自计算本地梯度，通过 AllReduce 聚合（求平均）后统一更新，保证各卡参数一致。

**第 48 题**
- **`stage` 字段作用**：指定 ZeRO 优化级别（0/1/2/3），控制对优化器状态、梯度、参数的分片程度，是"声明式"切换显存优化策略的核心开关。
- **参数放不进单卡时**：应选 **ZeRO-3**（或 FSDP 的 FULL_SHARD）。因为 ZeRO-1/2 每卡仍保留**完整模型参数**，只切分优化器状态与梯度，无法解决"参数本身超单卡显存"的问题；只有 ZeRO-3 会把参数也切分到各卡，用时再临时 All-Gather，从而突破单卡参数上限。

### KB-15　模型推理部署（vLLM）

**第 49 题** 　**B**
自回归生成中，历史 Token 的 K/V 可复用，KV Cache 缓存它们以避免重复计算，将逐步生成的复杂度大幅降低。

**第 50 题** 　**正确**
Temperature 对 logits 缩放：温度越高分布越平缓、随机性越强；温度趋近 0 时概率集中于最大项，近似贪心解码。

**第 51 题**
PagedAttention 借鉴操作系统虚拟内存分页机制：将 KV Cache 切分为固定大小的**块（Block）**，块在物理显存中**无需连续**存储；通过**块表（Block Table）**将逻辑上连续的 KV Cache 映射到物理上不连续的显存块。这样几乎消除显存碎片，显著提升显存利用率与并发吞吐。
