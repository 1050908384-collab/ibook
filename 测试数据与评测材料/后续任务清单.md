## 1. 核对 50 组证据完整性

- [ ] 检查 `case_001` 至 `case_050` 是否全部存在。

完成标准：50 组可追溯，6 组有阶段 2，缺文件先记录，不手工补造。

## 2. 核对题库与题目字段

- [ ] 确认题库数据库和 seed 文件一致。
- [ ] 确认题型只使用 `single_choice`、`true_false`、`fill_blank`、`short_answer`、`practical`。
- [ ] 确认每个知识点至少有 2 道可抽取专属题。
- [ ] 确认每道题都有 `subtopic_id`。

完成标准：题库结构通过现有题库测试；不直接改 raw_outputs。

## 3. 核对阶段题量达标率

- [ ] 以每个阶段规划的 `subtopic_ids` 为知识点集合。
- [ ] 每个知识点目标题量固定为 2 道。
- [ ] 精准题数按同一 `subtopic_id` 统计，每个知识点最多计 2 道。
- [ ] 记录额外同板块兜底题数量。

完成标准：报告同时给出“精准匹配率”和“每知识点 2 题达标率”，不混用两个口径。

## 4. 核对主观题判分证据

- [ ] 列出所有 `short_answer` 和 `practical` 题。
- [ ] 检查每题是否有 rubric、评分规则或参考要点。
- [ ] 检查是否保存学习者提交答案。
- [ ] 检查是否有 Agent6/LLM 判分结果、分数或等级及依据。
- [ ] 没有判分证据的题目标记为“不可判分”，不得使用模拟 `is_correct` 冒充。

完成标准：主观题的“可判分率”只统计有真实判分证据的题目。

是否调用云端 LLM：统计本身不需要。只有确实缺少判分证据且决定补做定向判分时，才调用一次真实判分链路，并保存日志。

- [ ] `actual_evidence` 必须引用实际输出字段或原文。
- [ ] `verdict` 只能填 `pass`、`fail` 或 `error`。

完成标准：不再有 `not_reviewed`，得到正式画像适配率。

## 6. 人工审核领域事实

完成标准：得到人工事实错误率；Agent4 的自动审核比例只能作为辅助指标。
