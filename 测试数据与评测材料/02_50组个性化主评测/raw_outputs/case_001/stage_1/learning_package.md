## 块 8

### SSH 远程连接：让 Windows 指挥 Ubuntu

你的目标是 LoRA 微调，后面要在服务器或虚拟机上跑训练脚本。SSH 就是你的“远程遥控器”——装好它，你就能在 Windows 终端里直接操作 Ubuntu，不用来回切换窗口。

**动手操作（跟着敲就行）：**

1. **打开终端**：在 Ubuntu 桌面空白处点右键 → 选“在终端中打开”。如果右键没这个选项，按 `Ctrl + Alt + T` 也行。

2. **安装 SSH 服务**：在终端里逐行输入以下命令（每输完一行按回车）：

```bash
# 第1步：刷新软件列表（就像刷新应用商店）
sudo apt update

# 第2步：安装 SSH 服务端和网络工具
#     openssh-server：让别的电脑能远程连过来
#     net-tools：提供 ifconfig 命令，用来查 IP 地址
sudo apt install -y openssh-server net-tools

# 第3步：设置开机自动启动
sudo systemctl enable ssh

# 第4步：立刻启动 SSH
sudo systemctl start ssh
```

> **sudo 是什么？** 就是“以管理员身份执行”。Linux 里普通用户不能随便装软件，加 sudo 就是申请最高权限。输入后会让你输密码，**屏幕不会显示任何字符**（连 `***` 都没有），这是正常的安全设计，盲打完按回车就行。

3. **查 IP 地址**：

```bash
ifconfig
```

4. 输出内容很多，找到类似 `inet 192.168.xxx.xxx` 的那一行，那一串数字就是 IP 地址。**记下来！** 比如 `192.168.126.128`。

5. **测试连接**：回到 Windows，按 `Win + R`，输入 `cmd` 回车，打开命令提示符，输入：

```bash
ssh username@192.168.xxx.xxx
```

把 `username` 换成你自己的 Ubuntu 用户名，IP 换成你记下的地址。

6. 提示输入密码时，输入 Ubuntu 的密码并回车。看到 `Welcome to Ubuntu` 之类的欢迎信息，就说明连接成功了！

**常见坑预警：**
- 提示 `connection refused`：回到 Ubuntu

### 4.3 配置 SSH 密钥登录（安全第二步）

**为什么先做这个？** 你马上要用云服务器跑 LoRA 微调，如果只用密码登录，服务器容易被暴力破解。配好密钥后，登录既安全又不用每次输密码，省下的时间正好留给训练。

**操作步骤（Windows 本地 → 云服务器）：**

1. **生成密钥对**：按 `Win + R` 输入 `cmd` 打开命令提示符，执行：
   ```bash
   ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
   ```
2. **一路回车**：遇到 `Enter file...` 直接回车（用默认路径）；遇到两次 `Enter passphrase` 也都直接回车（不设密码短语）。看到 randomart image 即生成成功。
3. **查看公钥**：在命令提示符里执行：
   ```bash
   type %USERPROFILE%\.ssh\id_rsa.pub
   ```
   复制全部输出内容。
4. **登录服务器**：通过云厂商的 VNC/远程连接进入服务器，执行：
   ```bash
   su - yourname
   mkdir -p ~/.ssh
   nano ~/.ssh/authorized_keys
   ```
5. **粘贴公钥**：在 nano 编辑器里粘贴刚才复制的内容

重命名的本质就是“在同一目录下移动”：

```bash
# 把 a.txt 改名为 b.txt
mv a.txt b.txt

# 移动的同时改名：hello.py 移入 backup 并改名为 hello_v2.py
mv hello.py ./backup/hello_v2.py
```

## 8.3 安全选项

```bash
# 覆盖前先询问（推荐日常使用）
mv -i old.txt new.txt

# 强制覆盖，不提示（慎用）
mv -f old.txt new.txt
```

## 新手避坑指南

**1. 区分文件和文件夹**：`ls -l` 第一列是 `d` 表示文件夹，是 `-` 表示文件。对文件夹操作别忘了 `-r`（如 `cp -r`、`rm -r`）。

**2. 路径写错**：切换目录或复制文件时，路径写错会提示 "No such file or directory"，可先用 `pwd` 和 `ls` 确认当前位置和目录内容。

**3. 路径中包含空格必须用引号包裹**：如果文件夹或文件名包含空格，命令行会把它当成多个参数。务必用双引号包裹：

```bash
# 错误：mkdir my folder 会创建两个文件夹 my 和 folder
# 正确：
mkdir "my folder"
cd "my folder"
touch "my file.txt"
cp "my file.txt" ./backup/
rm "my file.txt"
```

**4. 文件名以 `-` 开头时使用 `--`**：Linux 命令中 `-` 开头通常表示选项。如果文件名本身以 `-` 开头，命令会误把文件名当选项解析。用 `--` 告诉命令"后面都是文件名，不是选项"：
