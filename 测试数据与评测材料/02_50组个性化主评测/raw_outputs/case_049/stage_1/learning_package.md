## 1.1 Python 解释器：程序的“翻译官”

你现在的目标是学 LoRA 微调，但先别急着碰模型——所有大模型工具，第一步都是让电脑能“听懂”你写的代码。这一节就是打这个地基。

**一句话理解**：你写的 Python 代码是给人看的文字，电脑只认 0 和 1。**Python 解释器**就是那个“翻译官”，把你的代码翻译成电脑能执行的指令。

**关键点**：没有解释器，你写的 `.py` 文件只是一堆普通文本，电脑根本不会运行它。

**对你意味着什么**：以后你跑 LoRA 微调脚本（比如用 HuggingFace 的库），本质上就是让 Python 解释器去“翻译”并执行那一大段训练代码。所以，先把“翻译官”请进门，后面才谈得上微调。

### 5.1 为什么用 Conda

你正用手机或平板学习，目标是掌握 LoRA 微调。这意味着后续要安装 PyTorch 等深度学习依赖，它们彼此关联复杂。**Conda** 是目前最主流的虚拟环境管理工具，它不仅能像普通虚拟环境那样为每个项目创建独立的 Python 空间，还能直接管理不同版本的 Python 解释器本身。对深度学习而言，conda 几乎是必备工具，它能帮你把项目依赖隔离干净，避免版本冲突。

### 5.2 安装 Conda：Anaconda vs Miniconda

两个选择，按你的场景推荐后者：

| 选项 | 特点 | 推荐人群 |
|------|------|----------|
| **Anaconda** | 体积较大（通常 800MB 以上），预装大量数据科学库（numpy、pandas、jupyter 等） | 做数据分析、不想手动装包的用户 |
| **Miniconda** | 体积小（约 80MB），只包含 conda 和基础 Python，按需安装 | 希望环境干净、做项目开发的用户 |

**推荐 Miniconda**，因为环境更干净，后续需要什么装什么，适合你从零搭建微调环境。

**安装步骤（手机/平板上操作同样适用）：**

1. 访问 https://docs.conda.io/en/latest/miniconda.html。
2. 下载对应系统的安装包（Windows 选 `.exe`，macOS 选 `.pkg` 或 `.sh`，Linux 选 `.sh`）。
3. 运行安装程序：
   - **Windows**：一路下一步，**保持默认、不要勾选 "Add Miniconda3 to my PATH environment variable"**（安装器标为"不推荐"）。直接塞进系统 PATH 容易和已有 Python / 工具冲突，导致 `python`、`pip` 指向不明。日常改用开始菜单里的 **"Anaconda Prompt (Miniconda3)"** 来使用 conda。
   - **macOS/Linux**：运行 `.sh` 文件后，按提示输入 `yes` 同意协议、选择安装路径，最后一步选 `yes`
