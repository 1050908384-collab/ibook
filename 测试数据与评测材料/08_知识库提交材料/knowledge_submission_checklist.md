# 知识库提交前核验清单

## A. 数量和映射

- [ ] 73 个知识点全部出现在 `knowledge_subtopic_catalog.csv`。
- [ ] 73 篇原始 Markdown 全部有唯一 `subtopic_id` 映射。
- [ ] 68 条运行资料全部能回指到知识点和原始文章；无法回指的必须单独说明。
- [ ] 15 个知识板块、73 个知识点与图谱节点数量一致。
- [ ] 知识点前置关系与 `knowledge_subtopics.json`、图谱关系一致。

## B. 来源和授权

- [ ] 每个参考网址可以访问，标题与文章中的引用一致。
- [ ] 官方文档、论文、课程、博客分别标注来源类型。
- [ ] 作者、机构和发布日期以原文为准；未知字段不猜测。
- [ ] 补充作者和网址时保留核验日期、核验人和备注。
- [ ] 写明第三方内容的引用、授权和展示边界。

## C. 内容质量

- [ ] 每篇文章有明确目标、适用人群、前置知识、操作步骤和验证结果。
- [ ] 命令、版本、显存、阈值和配置经过人工复核。
- [ ] 示例代码能运行，或明确标记为伪代码/示意代码。
- [ ] 事实性陈述能回指来源；争议性结论有限制条件。
- [ ] 文章中的路径、账号、密钥、个人信息和本机路径已脱敏。

## D. 题库和运行链路

- [ ] 每个知识点至少有 2 道题。
- [ ] 题目 `subtopic_id`、`block_id` 和知识点目录一致。
- [ ] 选择题、填空题、判断题的总体题型分布有统计。
- [ ] 主观题和实操题有参考答案、rubric 或真实判分证据。
- [ ] 运行时抽题使用的题目版本与提交题库版本一致。

## E. 提交包

- [ ] 提交包包含知识库说明、目录表、来源登记表、题库覆盖表和版本 Hash。
- [ ] 提交包包含图谱派生说明、向量库说明和构建命令。
- [ ] 提交包不包含 `backend/.env`、API Key、缓存和无关临时文件。
- [ ] 评委可依据 `subtopic_id`、`doc_id`、`question_id` 回溯完整证据。
