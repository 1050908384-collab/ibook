# 真实测试数据运行说明

## 一、环境准备

### 1.1 Python 依赖

```bash
cd d:\code\ai_agent-trainer
pip install -r requirements.txt
```

### 1.2 数据库初始化

```bash
python scripts/init_db.py
python scripts/init_knowledge_base.py
```

### 1.3 模型配置

编辑 `backend/.env`（复制 `backend/.env.example`）：

```env
# 主模型（云端 DeepSeek）
LLM_PROVIDER=deepseek
LLM_FALLBACK_PROVIDER=ollama
DEEPSEEK_API_KEY=你的真实密钥
DEEPSEEK_MODEL=deepseek-chat

# 回退模型（本地 Ollama）
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=deepseek-r1:7b
```

**安全要求**：
- 不得将 API Key 提交 Git、放入压缩包或截图
- `.gitignore` 必须包含 `backend/.env`
- `backend/.env.example` 中保持占位符 `your-deepseek-api-key`

### 1.4 启动 Ollama（可选，用于回退测试）

```bash
ollama pull deepseek-r1:7b
ollama pull qwen3-embedding:0.6b
ollama serve
```

### 1.5 验证配置

```bash
# 确认 .env 被读取
python -c "from backend.config import settings; print(f'Provider={settings.LLM_PROVIDER}, HasKey={bool(settings.DEEPSEEK_API_KEY) and settings.DEEPSEEK_API_KEY != \"your-deepseek-api-key\"}')"
```

## 二、运行前联调

**不要直接运行 50 组**。先用 `case_001` 做真实联调：

```bash
python scripts/run_real_evaluation.py --case-id case_001
```

联调确认事项：

1. `raw_outputs/case_001/run_manifest.json` 中 `model_config.has_deepseek_key` 为 `true`
2. `raw_outputs/case_001/llm_calls.jsonl` 中 `actual_model` 为 `deepseek-chat`
3. `raw_outputs/case_001/stage_1/learning_package.md` 非空且包含真实生成内容
4. `raw_outputs/case_001/stage_1/review_trace.json` 有真实审核记录
5. `raw_outputs/case_001/stage_1/stage_decision.json` 有真实策略和准确率
6. 耗时数据来自真实开始和结束时间（`latency_ms` 字段）
7. API Key 未出现在任何输出文件中

### 回退联调

临时将 `DEEPSEEK_API_KEY` 设为空，重新运行 `case_001`，确认：
- `llm_calls.jsonl` 中 `fallback_triggered` 为 `true`
- `actual_model` 切换为 Ollama 模型名

## 六、故障排查

### 6.1 DeepSeek API 不可用

- 检查 `DEEPSEEK_API_KEY` 是否正确
- 检查网络是否能访问 `https://api.deepseek.com`
- 系统会自动回退到 Ollama（如果配置了 `LLM_FALLBACK_PROVIDER=ollama`）

### 6.2 Ollama 连接失败

- 确认 `ollama serve` 正在运行
- 确认端口 11434 可访问
- 确认已 pull 模型：`ollama list`

### 6.3 数据库错误

- 重新运行 `python scripts/init_db.py`
- 确认 `data/sqlite_data/project.db` 存在且可写

### 6.4 知识库为空

- 运行 `python scripts/init_knowledge_base.py`
- 运行 `python scripts/build_knowledge_graph.py`

## 七、预计耗时

| 运行项 | 预计 LLM 调用 | 预计耗时 |
|---|---|---|
| 单场景（hybrid） | 8~20 次 | 2~5 分钟 |
| 4 组完整案例 | 40~80 次 | 10~20 分钟 |
| 50 组主评测 | 500~1000 次 | 2~4 小时 |
| 15×4 消融测试 | 600~1200 次 | 3~6 小时 |
| 12×2 可替换性 | 200~400 次 | 1~2 小时 |

实际耗时取决于 DeepSeek 响应速度和重试次数。
