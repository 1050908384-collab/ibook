##2. 测试案例与闭环流程

50个测试场景来自 `evaluation_cases.csv`，覆盖无编程基础、数据分析、前端开发、模型训练、工程部署等不同背景，并覆盖不同学习目标、已有基础、每日学习时间、学习偏好和硬件条件。评测入口将这些字段组织为自然语言学习者描述，验证系统对真实用户表达的诊断与个性化能力。

每组场景均执行以下闭环：

```text
清理用户运行时数据
→ 学情诊断与阶段规划 Agent
→ 阶段规划
→ 个性化学习资源生成 Agent
→ 专业知识与教学质量审核 Agent
→ 阶段测评与受控答题
→ 学情评估与动态决策 Agent
→归档运行清单、结果摘要、调用与事件记录
```

6个多阶段场景在阶段1后继续执行阶段2，验证系统依据测评反馈进行难度调整和学习路径决策的能力。

为形成提交材料中的完整端到端证据，主评测完成后于 2026-08-31 针对提交材料需要展示的三组重点用户画像进行复跑：初学者歧义目标画像（case_046）、低显存QLoRA实操画像（case_016）和工程全链路部署画像（case_026）。本次复跑目的是补充重点画像展示证据，不改变 50 组主评测统计口径。另以 case_04_fallback 开展独立的受控故障注入复现，验证云端不可用时的自动回退与状态连续性。
