# 测试报告目录

本目录用于最终量化报告，不直接替代原始测试输出。建议按以下顺序形成报告：

1. 测试目标、比赛要求和数据版本。
2. 50 组场景分布及 4 组完整案例索引。
3. 题库覆盖率、题目有效率和抽题匹配结果。
4. 画像适配人工审核结果。
5. 领域事实核验与 Agent4 修复结果。
6. 阶段决策、动态路径调整和多阶段案例结果。
7. 回退可靠性测试结果。
8. 10 组 Ollama 对照测试结果。
9. 失败案例、限制条件和数据真实性声明。
10. 最终指标、分子、分母和证据路径。

统计原始表保存在 `../06_指标统计/`，原始运行证据保存在 `../02_50组个性化主评测/`，冻结副本保存在 `../00_冻结备份/`。报告中的每一个数字都应能回指到这些目录中的文件。
