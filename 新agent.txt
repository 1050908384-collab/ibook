当前运行时 Agent 协作简述

说明：本文件已按当前 Harness 运行链路更新。Agent2 保留为逻辑职责名称，但当前实际阶段规划调用由 学情诊断与阶段规划 Agent 的 generate_stage 承担；Agent5 的质量审核能力已合并到 专业知识与教学质量审核 Agent。

学情诊断与阶段规划 Agent：学情诊断与阶段选路
- 输入：用户表单字段、用户原始描述、当前画像
- 处理：表单字段作为事实源；别名精确匹配与 学情诊断与阶段规划 Agent 专用轻量中文语义索引联合召回；LLM 只在候选板块内细化知识盲区
- 输出：画像 JSON、受约束的 knowledge_gaps、画像置信度、必要时的追问
- 规则：不能自由创造 block_id；证据不足或属于目录外领域时返回低置信度，不硬选板块
- 阶段：通过 generate_stage 根据 subtopic_status、板块级先修和子知识点直接先修选择当前/下一阶段

Agent2：路径规划逻辑角色
- 当前 Harness 不直接实例化 Agent2 文件
- 运行时选路由 学情诊断与阶段规划 Agent.generate_stage 完成，仍遵循知识图谱、daily_hours 和 subtopic_status 约束

个性化学习资源生成 Agent：内容生成与答疑
- 输入：当前阶段 block_id/subtopic_id、用户画像、审核意见或用户问题
- 输出：学习资料包、代码、题库题目、用户问题答案

专业知识与教学质量审核 Agent：统一技术与教学质量审核
- 输入：个性化学习资源生成 Agent 的学习包或答案
- 处理：技术准确性、幻觉、代码、行业规范、难度、认知负荷、风格和资源关联审核
- 输出：审核结果与结构化 issue；原 Agent5 的质量审核能力已合并在此

学情评估与动态决策 Agent：阶段决策与学习状态更新
- 输入：正确率、qa_history、interactions、当前画像
- 输出：阶段总结、策略、更新后的学习状态
- 允许更新：status、progress、skill、prerequisites 等学习状态字段
- 必须保留：学情诊断与阶段规划 Agent 生成的 block_id、block_name、target_subtopic_ids、mapping_confidence；学情评估与动态决策 Agent 不重新映射知识板块

Orchestrator：流程编排
- 低置信画像：返回 学情诊断与阶段规划 Agent 的追问，不生成阶段
- 画像达标：调用 学情诊断与阶段规划 Agent.generate_stage，生成当前阶段
- 阶段开始：调用 个性化学习资源生成 Agent，再交 专业知识与教学质量审核 Agent 统一审核
- 阶段完成：只调用 学情评估与动态决策 Agent 保存结果；complete_stage 不自动生成下一阶段
- 用户确认继续：调用 plan-next，由 学情诊断与阶段规划 Agent.generate_stage 生成并保存 next_stage
- 全部 knowledge_gaps 掌握后：结束 session 并生成结业报告

初始化与交付
- 开发/部署侧执行：python scripts/init_agent1_semantic_index.py
- 首次执行会下载约 90MB 的 FastEmbed BAAI/bge-small-zh-v1.5，并缓存到 data/fastembed_models/
- 评测命令：python scripts/evaluate_agent1_retrieval.py
- 普通用户发行包应预置 data/fastembed_models/ 与已初始化的 data/chroma_db/；用户不需要下载 embedding 模型、启动 embedding Ollama 或执行初始化脚本
